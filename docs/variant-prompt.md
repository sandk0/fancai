# Промпт для Variant.com — fancai

## Текст промпта

---

Мобильное PWA-приложение «fancai» — AI-ридер книг с интерактивной Entity Wiki и генерацией иллюстраций. Пользователь загружает EPUB/FB2 книги, читает их в полноэкранном ридере с жестовой навигацией (свайпы, тапы), получает AI-сгенерированный глоссарий персонажей/локаций/объектов с защитой от спойлеров по главам, видит AI-иллюстрации по описаниям из текста, делает закладки и выделения, ведёт заметки. Приоритет — русскоязычные книги. Интерфейс двуязычный (русский/английский). Целевая аудитория — активные читатели 20–45 лет, которые хотят более глубокого погружения в книгу.

Нужен полный комплект экранов для mobile-first PWA (основной формат — телефон 375–430px, адаптация под планшет и десктоп).

---

### Экран 1: Лендинг (гостевой)

Промо-страница для неавторизованных пользователей. Hero-секция с заголовком и описанием ценности продукта — «AI-ридер, который понимает книгу вместе с вами». Блок с 3–4 ключевыми фичами: Entity Wiki (AI-глоссарий персонажей без спойлеров), AI-иллюстрации по описаниям из текста, жестовая навигация как в Apple Books, offline-чтение. Кнопки «Войти» и «Зарегистрироваться». Внизу страницы — минимальный футер.

---

### Экран 2: Авторизация

Экран входа — центрированная форма с логотипом приложения сверху. Поля: email, пароль (с переключателем видимости). Кнопка «Войти». Ссылки «Забыли пароль?» и «Создать аккаунт». Touch-friendly — минимальная высота полей 44px.

---

### Экран 3: Регистрация

Аналогичная форма: username, email, пароль, подтверждение пароля. Кнопка «Зарегистрироваться». Ссылка «Уже есть аккаунт? Войти».

---

### Экран 4: Главная (авторизованный пользователь)

Приветствие с именем пользователя. Карточка «Продолжить чтение» — обложка последней книги, прогресс чтения в процентах, кнопка «Читать». Секция «Недавние книги» — горизонтальная прокрутка карточек книг с обложками и прогрессом. Секция «Статистика» — компактные карточки: всего книг, часов чтения, найденных описаний, сгенерированных иллюстраций. В нижней части — мобильная нижняя навигация (tab bar) с 5 табами: Главная, Библиотека, Галерея, Настройки, Профиль.

---

### Экран 5: Библиотека

Основной экран управления книгами. Сверху — строка поиска по названию/автору. Фильтры: по жанру (выпадающий список), по статусу чтения (все / читаю / прочитано / не начато). Сортировка: по дате добавления, по названию, по прогрессу. Кнопка «+» для загрузки новой книги. Сетка книг — карточки с обложкой, названием, автором, индикатором прогресса чтения (тонкая полоска внизу карточки). По long-press на карточку — контекстное меню: читать, удалить, скачать. Pull-to-refresh для обновления списка. Пагинация или бесконечная прокрутка.

---

### Экран 6: Загрузка книги (модальное окно)

Модальное окно поверх библиотеки. Зона drag-and-drop для файла. Поддерживаемые форматы: EPUB, FB2. Превью после выбора файла: название, автор, формат, размер. Прогресс-бар загрузки и обработки (парсинг глав, извлечение описаний AI). Анимация успешной загрузки и кнопка «Перейти к книге».

---

### Экран 7: Страница книги (детали)

Hero-секция с обложкой книги и градиентным фоном. Метаданные: название, автор, язык, количество глав, дата добавления. Карточки статистики: прогресс чтения (круговой индикатор), количество глав, количество AI-изображений. Крупные action-кнопки: «Читать» (или «Продолжить с N%»), «Иллюстрации» (галерея). Кнопка назад в библиотеку.

---

### Экран 8: Ридер (полноэкранный режим чтения)

Самый важный экран. Полноэкранный режим по умолчанию (immersive mode) — шапка скрыта, максимум текста на экране.

**Шапка ридера (auto-hide):** появляется по тапу в центр экрана. Слева — кнопка «Назад» и кнопка оглавления. По центру — название книги и автор (только на десктопе). Справа — кнопки: Entity Wiki (иконка библиотеки), поиск, настройки. На узких экранах часть кнопок уходит в overflow-меню (⋮).

**Область текста:** рендеринг книги с настраиваемыми шрифтом, размером, межстрочным интервалом. В тексте подсвечены описания (выделены цветным фоном или подчёркиванием) — по тапу на подсвеченный текст открывается drawer с описанием и AI-иллюстрацией. Имена сущностей (персонажей, локаций) также кликабельны — по тапу открывается bottom sheet с карточкой сущности.

**Навигация:** свайп влево/вправо для перелистывания страниц с follow-finger анимацией и spring physics (как в Apple Books). Тап по левому/правому краю экрана — перелистывание назад/вперёд.

**Футер ридера:** тонкая полоска прогресса внизу экрана с номером текущей страницы/главы.

---

### Экран 9: Панель настроек ридера (выезжающая снизу)

Bottom sheet (Vaul drawer), появляющийся поверх ридера. Секции:

- **Тема:** 5 вариантов — светлая, тёмная, сепия, ночная (AMOLED чёрный), дневная (для улицы). Каждая тема — круглый превью-кружок с цветом фона.
- **Шрифт:** выбор из нескольких семейств (Georgia, системный, без засечек). Радиокнопки.
- **Размер шрифта:** слайдер от 12px до 32px.
- **Межстрочный интервал:** слайдер от 1.2 до 2.5.
- **Ширина текста:** узкая, средняя, широкая.
- **Режим навигации:** свайпы или скролл.
- **Анимации:** вкл/выкл (для слабых устройств).
- **Подсветка описаний:** вкл/выкл, режим (подчёркивание / фоновый цвет).

---

### Экран 10: Боковая панель оглавления (TOC)

Слайд-панель слева (на мобильных — fullscreen с Vaul). Три таба сверху:

- **Оглавление:** список глав книги с индикатором прочитанности (процент/галочка). Текущая глава подсвечена. По тапу — переход к главе.
- **Заметки:** список закладок и выделений пользователя. Каждая запись — текст выделения, цвет, заметка пользователя, номер главы. По тапу — переход к месту в книге. Свайп для удаления.
- **О книге:** метаданные — автор, издатель, дата, язык, права.

---

### Экран 11: Entity Wiki (выезжающий drawer)

Полноэкранный drawer (на мобильных) или боковая панель (на десктопе). Заголовок «Персонажи и локации». Строка поиска по имени сущности.

Список сущностей, сгруппированных по типу:
- **Персонажи** (иконка человечка) — имя, роль, краткое описание.
- **Локации** (иконка метки) — название, описание.
- **Объекты** (иконка куба) — название, описание.
- **Атмосфера/действия** — описания сцен.

Каждая карточка содержит: аватар/иконку типа, имя, краткую биографию (до текущей главы — спойлер-защита), бейдж с количеством упоминаний. По тапу на карточку — открывается полная страница сущности.

---

### Экран 12: Карточка сущности (Entity Bottom Sheet)

Bottom sheet, появляющийся снизу при тапе на имя сущности в тексте. Два snap-point: 30% и 60% экрана.

Содержимое: аватар/иконка типа, имя, тип (персонаж/локация/объект), роль в сюжете, краткая биография (до текущей главы читателя). Кнопка «Подробнее» — открывает полный drawer с Entity Wiki.

---

### Экран 13: Drawer описания + AI-иллюстрация

Bottom sheet, открывающийся при тапе на подсвеченное описание в тексте. Содержимое:

- Текст описания из книги.
- AI-сгенерированная иллюстрация (или кнопка «Сгенерировать иллюстрацию»).
- Если изображение есть — полноразмерный просмотр, кнопка «Сгенерировать заново».
- Прогресс генерации (спиннер / полоска прогресса при ожидании).
- Статус: «Генерация...», «Готово», «Ошибка».

---

### Экран 14: Выделение текста и tooltip

Когда пользователь выделяет текст в ридере — появляется floating tooltip над выделением. Кнопки: «Закладка» (сохранить выделение), «Заметка» (добавить текстовую заметку), «Копировать». Выбор цвета выделения (3–4 цвета).

---

### Экран 15: Поиск по книге

Панель, выезжающая сверху в ридере. Строка поиска с мгновенным вводом. Список результатов: каждый результат — фрагмент текста с подсвеченным совпадением, номер главы. По тапу — переход к месту в книге. Счётчик найденных совпадений.

---

### Экран 16: Галерея иллюстраций книги

Страница с hero-секцией (обложка книги, название). Сетка (masonry или grid) AI-сгенерированных иллюстраций для этой книги. Каждая карточка — изображение, текст описания снизу. По тапу — полноэкранный просмотр. Карточки статистики: количество глав, прогресс, количество изображений. Кнопка «Читать книгу».

---

### Экран 17: Общая галерея иллюстраций (все книги)

Коллекция всех AI-иллюстраций пользователя из всех книг. Фильтры по типу описания: все, локации, персонажи, атмосфера, объекты, действия. Сортировка: новые / старые / по книге. Сетка изображений с ленивой загрузкой. По тапу — модальный просмотр с текстом описания и названием книги. Пагинация (24 на страницу).

---

### Экран 18: Статистика чтения

Карточки с основными метриками: всего книг, книг в этом месяце, часов чтения, часов в этом месяце, страниц прочитано. Серия для чтения (streak) — текущая и рекордная. Недельная активность — столбчатая диаграмма по дням. Распределение по жанрам — круговая или столбчатая диаграмма. Топ книг по времени чтения. Список достижений (ачивки): первая книга, 7-дневная серия, 10 книг и т.д.

---

### Экран 19: Профиль пользователя

Hero-секция с аватаром (возможность загрузки фото), имя и email. Карточки статистики: книг прочитано, время чтения, достижений получено. Редактируемая информация: имя, email, пароль (кнопка «Редактировать»). Цели чтения (трекер). Кнопка «Выйти из аккаунта».

---

### Экран 20: Настройки

Экран с группами настроек (на десктопе — боковой таб-бар, на мобильных — аккордеон):

- **Аккаунт:** управление email, пароль, удаление аккаунта.
- **Чтение:** настройки по умолчанию (тема, шрифт, размер).
- **Уведомления:** push-нотификации, email-уведомления.
- **Конфиденциальность:** управление данными.
- **PWA:** установка на устройство, инструкции для iOS (Share → Add to Home Screen), обновление приложения, офлайн-кэш.
- **О приложении:** версия, лицензии, обратная связь.

---

### Экран 21: PWA Install Banner

Компактный баннер внизу экрана (над bottom nav) или встроенный блок на главной странице. Иконка приложения, текст «Установите fancai для быстрого доступа и офлайн-чтения». Кнопки: «Установить» и «✕» (закрыть). На iOS — отдельный экран с пошаговой инструкцией (скриншоты кнопки Share → Add to Home Screen).

---

### Экран 22: Страница 404

Минимальный экран. Крупная иконка книги, заголовок «Страница не найдена», описание, кнопка «На главную».

---

### Навигация и структура:

**Мобильная нижняя навигация (tab bar)** — 5 табов с иконками: Главная (Home), Библиотека (Library), Галерея (Image), Настройки (Settings), Профиль (User). Скрывается в режиме чтения (ридер — полноэкранный).

**Десктопная навигация:** верхний хедер с логотипом, боковая панель с навигацией. Нижний tab bar скрыт.

**Режим ридера:** отдельный fullscreen layout без стандартного хедера и навигации — собственная auto-hide шапка и футер.

---

### Ключевые пользовательские сценарии:

1. **Новый пользователь:** Лендинг → Регистрация → Библиотека (пустая) → Загрузка книги → Читать.
2. **Чтение книги:** Библиотека → Карточка книги → Ридер → Тап по описанию → Генерация иллюстрации → Продолжить чтение.
3. **Entity Wiki:** Чтение → Тап по имени персонажа → Bottom Sheet → «Подробнее» → Полный Entity Wiki с биографией до текущей главы.
4. **Заметки:** Чтение → Выделение текста → Tooltip → Закладка/Заметка → Оглавление → Таб «Заметки» → Переход к выделению.
5. **Галерея:** Нижняя навигация → Галерея → Фильтр по типу → Просмотр иллюстрации.
