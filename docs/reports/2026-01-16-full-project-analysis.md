# Полный анализ проекта fancai

**Дата:** 2026-01-16
**Scope:** Полный анализ всех компонентов без исключений
**Автор:** Claude Code (research-and-analysis skill)

---

## Executive Summary

**fancai** — веб-приложение для чтения художественной литературы с AI-генерируемыми изображениями из описаний в книгах. Проект находится на стадии MVP с ~87,600 строками кода (57,338 frontend + 30,262 backend).

**Ключевые находки:**
1. Архитектура качественная, но CI/CD отключена (критичная проблема)
2. UX имеет серьёзные проблемы с offline-режимом и синхронизацией
3. Производительность хорошая на frontend, но есть узкие места на backend
4. Стоимость AI-генерации (~$0.06/книга) оптимальна, но нет контроля пользователем

### 3.2 User Flows

#### Flow 1: Регистрация → Библиотека
```
/register → Форма → POST /auth/register → JWT → /library
```

#### Flow 2: Загрузка книги
```
/library → Upload Modal → POST /books/upload → Parsing → Книга в сетке
```

#### Flow 3: Чтение
```
/library → Book Card → /book/{id}/read → EpubReader → Навигация свайпами
```

#### Flow 4: Генерация изображений
```
Читалка → Клик на описание → Modal → "Генерировать" → Imagen API → Картинка
```

#### Flow 5: Настройки
```
/settings → Tabs → localStorage сохранение → Применение в читалке
```

## 4. Выявленные проблемы

### 4.1 Критические (P0)

| # | Проблема | Компонент | Impact |
|---|----------|-----------|--------|
| 1 | **CI/CD полностью отключена** | `.github/workflows_disabled/` | Нет автотестов, нет security scan |
| 2 | **PostgreSQL версии конфликтуют** | Docker Compose | v15 vs v17 может сломать миграцию |
| 3 | **Нет rate limit на upload** | `/books/upload` | DoS vulnerability |
| 4 | **Memory exhaustion на staging** | Celery worker | 4GB сервер, Celery может OOM |
| 5 | **Отсутствует "Забыли пароль"** | Auth flow | Пользователи теряют доступ |

### 4.2 Высокие (P1)

| # | Проблема | Компонент | Impact |
|---|----------|-----------|--------|
| 6 | **Настройки читалки только локальные** | useReaderStore | Теряются на новом устройстве |
| 7 | **Нет offline режима** | Reader | Нельзя читать без сети |
| 8 | **CFI нестабилен** | useCFITracking | Позиция может потеряться |
| 9 | **Медленная загрузка больших книг** | epub.js | >10MB парсится долго |
| 10 | **Нет контроля генерации** | Image flow | Пользователь не выбирает что генерировать |
| 11 | **Imagen timeout 60s** | imagen_generator.py | Может не хватить в peak |
| 12 | **JSON repair теряет данные** | gemini_extractor.py | Описания могут пропадать |

### 4.3 Средние (P2)

| # | Проблема | Компонент | Impact |
|---|----------|-----------|--------|
| 13 | **Нет мониторинга** | Инфраструктура | Проблемы не видны |
| 14 | **Нет поиска по тексту** | Reader | epub.js ограничение |
| 15 | **LCS O(nm) медленный** | useDescriptionHighlighting | Большие главы тормозят |
| 16 | **Test coverage ~65%** | Backend | Недостаточно |
| 17 | **Нет backup strategy** | PostgreSQL | Риск потери данных |
| 18 | **Redis memory на staging** | 384MB limit | Может вытеснять кэш |

### 4.4 UX/UI проблемы

| # | Проблема | Где | Серьёзность |
|---|----------|-----|-------------|
| 19 | **Валидация пароля сложная** | Register | Средняя |

## 9. Заключение

### Сильные стороны проекта

- ✅ Качественная архитектура frontend (декомпозиция, hooks)
- ✅ Современный стек технологий (React 19, FastAPI, Vite 6)
- ✅ Оптимальная стоимость AI (~$0.06/книга)
- ✅ PWA с offline кэшированием
- ✅ Хорошая типизация (TypeScript + Pydantic)

### Критические пробелы

- ❌ CI/CD отключена (main blocker для production)
- ❌ Нет мониторинга и alerting
- ❌ Offline чтение не работает полностью
- ❌ Настройки не синхронизируются между устройствами

### Итоговая оценка

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| **Код качество** | 8/10 | Хорошая архитектура, можно улучшить тесты |

| **Производительность** | 7/10 | Frontend хорошо, backend имеет узкие места |
| **Безопасность** | 5/10 | Базовая, нет rate limits везде |
| **Инфраструктура** | 4/10 | CI/CD отключена, нет monitoring |
| **Production Ready** | 60% | Требует 2-4 недели стабилизации |
