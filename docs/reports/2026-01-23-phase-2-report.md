# Отчет о выполнении Фазы 2: Логика и Интеллект

**Дата:** 23 января 2026
**Статус:** Выполнено

## Выполненные работы

### 1. Map-Reduce Entity Resolution (`consistency_manager.py`)
Реализован механизм "Map-Reduce" для очистки данных:
-   **Map Phase**: Параллельное извлечение сущностей в `gemini_extractor.py` (уже работало).
-   **Reduce Phase**: Добавлен метод `optimize_book_entities`, который запускается после обработки всех глав ("Barrier").
    -   Собирает все сущности книги.
    -   Отправляет их списком в Gemini с инструкцией: *"Найди дубликаты (Гарри = Поттер) и удали мусор (Importance < 7)"*.
    -   Выполняет `UPDATE` и `DELETE` запросы к БД на основе ответа LLM.

### 2. Knowledge Graph Engine (`graph_service.py`)
Внедрен сервис графового анализа:
-   **Стек**: BiblioGraph schema + NetworkX.
-   **PageRank**: Алгоритм запускается для всей книги, вычисляя "авторитетность" узлов на основе связей.
-   **Normalization**: Значение PageRank нормализуется в шкалу 1-10 и записывается в поле `Entity.importance`. Это позволяет автоматически определять протагонистов, даже если LLM явно этого не сказал.

### 3. Pipeline Integration (`tasks.py`)
Цепочка обработки книги теперь выглядит так:
1.  **Parallel Extract** (TaskGroup) -> Raw Entities.
2.  **Barrier 1**: `optimize_book_entities` (Склейка дублей).
3.  **Barrier 2**: `calculate_pagerank` (Расчет важности).
4.  **Master Gen**: Генерация эталонных портретов (только для важных сущностей).

## Результат
Система получила "мозг". Она не просто парсит текст, но и осмысливает структуру персонажей, удаляя галлюцинации и выделяя главное перед дорогостоящей генерацией изображений.
