## Executive Summary

Проведено комплексное исследование для разработки iOS-версии fancai — приложения для чтения книг с AI-генерацией иллюстраций из текстовых описаний.

### Ключевые рекомендации

| Категория | Решение |
|-----------|---------|
| **Язык** | Swift 6.2 с Strict Concurrency |
| **UI Framework** | SwiftUI + UIKit interop для EPUB WebView |
| **Архитектура** | MVVM или TCA (The Composable Architecture) |
| **EPUB библиотека** | Readium Swift Toolkit (R2) |
| **База данных** | SwiftData (iOS 17+) |
| **Кэширование изображений** | Nuke |
| **AI-консистентность** | fal.ai FLUX + PuLID ($0.02/image) |
| **Подписка** | **699 ₽/месяц** ($8.99) |
| **Минимальная iOS** | iOS 17+ |

## Часть I: Ответы на контрольные вопросы

### 1. Reader функциональность

#### 1.1 Tap-зоны vs Swipe — что использовать?
**Ответ:** Оба. Kobo, Kindle, Apple Books поддерживают оба режима с возможностью настройки.

**Рекомендация для fancai:**
- По умолчанию: Tap + Swipe (оба)
- Настройка в Settings: "Только tap", "Только swipe", "Оба"
- Tap-зоны: 25% / 50% / 25% (prev / UI toggle / next)

#### 1.2 Анимация перелистывания — Page Curl или Slide?
**Ответ:** Page Curl для "книжного" опыта, Slide для современного минималистичного.

**Рекомендация:**
- По умолчанию: **Slide** (современный стандарт)
- Альтернативы в настройках: Page Curl, Fade, None
- Реализация: `UIPageViewController` с `.pageCurl` для Page Curl

#### 1.3 Какой Haptic feedback использовать?
**Ответ:**

| Действие | Тип Haptic | Класс |
|----------|-----------|-------|
| Перелистывание страницы | `.light` impact | `UIImpactFeedbackGenerator` |
| Добавление закладки | `.success` notification | `UINotificationFeedbackGenerator` |
| Конец главы/книги | `.medium` impact | `UIImpactFeedbackGenerator` |
| Выделение текста | Selection changed | `UISelectionFeedbackGenerator` |
| Ошибка | `.error` notification | `UINotificationFeedbackGenerator` |

#### 1.4 Поддержка ориентации экрана?
**Ответ:**
- **iPhone:** Portrait по умолчанию, Landscape для fullscreen изображений
- **iPad:** Обе ориентации. В Landscape — двухколоночный layout (как книга)

### 2. Кастомизация чтения

#### 2.1 Какие шрифты включить?
**Ответ:** Минимальный набор с поддержкой кириллицы:

| Шрифт | Тип | Назначение |
|-------|-----|------------|
| **Georgia** | Serif | По умолчанию для чтения |
| **Literata** | Serif | Open-source, оптимизирован для экранов |
| **SF Pro Text** | Sans-serif | Системный iOS |
| **OpenDyslexic** | Accessibility | Для пользователей с дислексией |
| **Fira Sans** | Sans-serif | Поддержка кириллицы |

**Встроенные шрифты книги:** Уважаем, если указаны в EPUB.

#### 2.2 Темы оформления?
**Ответ:** 4 базовые темы:

| Тема | Фон | Текст |
|------|-----|-------|
| Light | #FFFFFF | #1C1C1E |
| Dark | #1C1C1E | #F5F5F5 |
| Sepia | #F4ECD8 | #5B4636 |
| System | Follows iOS | Auto |

Дополнительно: Возможность создания custom тем (Pro функция).

### 3. Аутентификация

#### 3.1 Какие методы аутентификации поддержать?
**Ответ:**

| Метод | Приоритет | Примечание |
|-------|-----------|------------|
| **Sign in with Apple** | P0 | Обязателен для App Store |
| **Email + Password** | P0 | Классический метод |
| **Sign in with Google** | P1 | Популярен среди пользователей |
| **Telegram Login** | P2 | Популярен в РФ |

**JWT реализация:** Используем существующий бэкенд FastAPI с JWT токенами.

### 4. Библиотека книг

#### 4.1 Grid vs List view?
**Ответ:** Оба с переключателем. Grid по умолчанию (обложки важны).

#### 4.2 Сортировка?
**Ответ:**
- По умолчанию: Дата добавления (новые сверху)
- Дополнительно: Название A-Z, Автор A-Z, Прогресс, Рейтинг, Последнее чтение

#### 4.3 Коллекции — иерархические или плоские?
**Ответ:** Плоские (flat). Упрощает UX и синхронизацию.

#### 4.4 Серии книг — автогруппировка?
**Ответ:** Да. Парсим метаданные `calibre:series` и EPUB 3 `belongs-to-series`.

### 5. AI-функции

#### 5.1 Какие типы описаний извлекать по умолчанию?
**Ответ:**
- **Обязательные:** CHARACTER (персонажи)
- **По умолчанию включены:** LOCATION (локации)
- **По умолчанию выключены:** ATMOSPHERE, OBJECT, ACTION

#### 5.2 Highlight стиль по умолчанию?
**Ответ:**
- Цвет: Голубой (#007AFF, iOS system blue)
- Стиль: Background с opacity 40%
- Tap на highlight: Открывает Entity Card

#### 5.3 Стили генерации?
**Ответ:** 8 стилей:
1. Realistic (photorealistic)
2. Digital Art
3. Anime/Manga
4. Watercolor
5. Oil Painting
6. Sketch
7. Fantasy
8. Noir

По умолчанию: **Realistic**

### 6. Социальные функции

#### 6.1 Шеринг цитат — какой формат?
**Ответ:** Изображение-карточка с:
- Текстом цитаты
- Названием книги и автором
- Логотипом fancai
- Опционально: обложка книги

**Каналы:** System share sheet (поддерживает все соцсети).

#### 6.2 Шеринг AI-изображений?
**Ответ:**
- Формат: PNG с высоким разрешением
- Водяной знак: Опционально, для Free tier
- Метаданные: Сохраняем название книги и персонажа

### 7. Gamification

#### 7.1 Какие метрики отслеживать?
**Ответ:**
- Книги прочитано (всего / за период)
- Страницы / слова прочитано
- Время чтения
- Серии streak (дни подряд)

#### 7.2 Достижения — какие?
**Ответ:** Минимальный набор (10-15):
- First Book Read
- 10 / 50 / 100 Books
- Week Streak / Month Streak
- Night Owl (чтение после 22:00)
- Early Bird (чтение до 7:00)
- Genre Explorer (5 разных жанров)

### 8. iOS системные функции

#### 8.1 Виджеты — какие?
**Ответ:**
- **Small:** Текущая книга с прогрессом
- **Medium:** Текущая книга + статистика дня
- **Large:** Библиотека с 4-6 обложками

#### 8.2 Dynamic Island — для чего?
**Ответ:** Только для обработки книги (extraction).
- Показывает прогресс обработки
- Не используется для чтения (слишком отвлекает)

#### 8.3 Live Activities?
**Ответ:** Да, для обработки книги.
- Прогресс extraction
- Текущая глава
- Оставшееся время

### 9. Синхронизация

#### 9.1 Что синхронизировать через iCloud?
**Ответ:**
- Позиция чтения (CFI)
- Закладки
- Заметки и highlights пользователя
- Настройки
- Коллекции

**Не синхронизируем:** Файлы книг (слишком большие), сгенерированные изображения.

#### 9.2 Разрешение конфликтов?
**Ответ:** Last-write-wins с возможностью просмотра истории изменений.

### 10. Push-уведомления

#### 10.1 Какие типы уведомлений?
**Ответ:**
- Генерация завершена (background processing)
- Напоминание о чтении (daily, настраиваемое)
- Новые функции / обновления

#### 10.2 Технология?
**Ответ:** Firebase Cloud Messaging (FCM) через существующий FastAPI backend.

### 11. Тестирование и CI/CD

#### 11.1 Какой уровень покрытия тестами?
**Ответ:**
- Unit tests: 70%+ coverage
- UI tests: Критические пути (onboarding, purchase, reading)
- Snapshot tests: UI компоненты

#### 11.2 CI/CD pipeline?
**Ответ:** GitHub Actions → Xcode Cloud:
- Build на каждый PR
- Tests на каждый PR
- TestFlight deploy на merge в main
- App Store deploy на tag

### 12. App Store Guidelines

#### 12.1 Как обойти ограничения IAP?
**Ответ:** Нельзя "обойти". Используем StoreKit 2 / RevenueCat:
- 15-30% комиссия Apple
- Альтернатива: Reader Rule (ссылка на внешнюю подписку) — требует одобрения Apple

#### 12.2 Privacy — что нужно?
**Ответ:**
- Privacy Policy на сайте
- App Privacy Labels в App Store Connect
- GDPR compliance: право на удаление данных
- ATT (App Tracking Transparency) если используем tracking

## Часть II: Самостоятельные решения

Ниже приведены решения, которые были определены на основе исследования без прямого указания в требованиях.

### Reader

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Действие при double-tap | **Zoom** (для изображений) | Стандарт iOS, используется в Apple Books и Kindle |
| Единицы прогресса | **Время** ("~45 мин до конца главы") | Наиболее практично, требует калибровки WPM |
| Скорость чтения по умолчанию | **250 WPM** | Средняя скорость взрослого читателя |
| Количество preload страниц | **3 вперёд, 1 назад** | Баланс между производительностью и памятью |
| Размер tap-зоны | **25%/50%/25%** | Стандарт Kindle/Apple Books |
| Минимальный touch target | **44x44 points** | Apple HIG requirement |

### Библиотека

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Лимит книг Free tier | **10 книг** | Достаточно для оценки, мотивирует upgrade |
| Лимит офлайн книг Free tier | **3 книги** | Позволяет пользоваться в путешествии |
| Алгоритм дубликатов | **SHA256 hash + ISBN + fuzzy title** | Надёжный многоуровневый подход |
| Соотношение сторон обложки | **2:3** | Стандарт книжных обложек |
| Минимальная ширина ячейки grid | **100pt** | Читаемость на iPhone SE |

### AI-функции

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Лимит генераций Free tier | **30 изображений/месяц** | Покрывает затраты ~$0.60, позволяет попробовать |
| Лимит генераций Pro tier | **300 изображений/месяц** | Unit economics: $6 + buffer |
| Регенерации на изображение | **3 раза** | Предотвращает злоупотребление |
| Стиль по умолчанию | **Realistic** | Наиболее универсальный |
| Изображения из будущих глав | **Не скрываются** | Пользователь явно запрашивает генерацию |
| Удаление изображений с книгой | **Нет** | Изображения принадлежат пользователю |
| Длина цитаты для шеринга | **До 500 символов** | Читаемость в соцсетях |

### Ценообразование

| Параметр | Решение | Обоснование |
|----------|---------|-------------|
| Цена подписки | **699 ₽/месяц** ($8.99) | Unit economics: маржа ~5% при 300 img/month |
| Годовая подписка | **5,990 ₽/год** (~499 ₽/мес) | Скидка 29%, стимулирует annual |
| Trial период | **7 дней** | Стандарт App Store |
| Family Sharing | **Нет** (v1) | Усложняет unit economics |

### Технические

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Минимальная iOS | **iOS 17** | SwiftData, современный SwiftUI |
| Поддержка iPad | **Да** | Universal app |
| Поддержка Mac (Catalyst) | **Нет** (v1) | Фокус на мобильные устройства |
| Архитектура | **MVVM** | Проще чем TCA, подходит для размера проекта |
| State management | **@Observable + SwiftData** | Современный подход iOS 17+ |
| Networking | **URLSession + async/await** | Нативно, без зависимостей |

### Синхронизация

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Конфликты позиции чтения | **Last-write-wins** | Простота, обычно пользователь на одном устройстве |
| Синхронизация файлов книг | **Нет** | Слишком большие, используем iCloud Drive |
| Синхронизация изображений | **Только метаданные** | Изображения можно перегенерировать |

### UX/UI

| Вопрос | Решение | Обоснование |
|--------|---------|-------------|
| Onboarding | **3 экрана** | Коротко: возможности, импорт первой книги, подписка |
| Dark mode | **System default** | Уважаем настройки пользователя |
| Haptic по умолчанию | **Включен** | Улучшает UX, можно отключить |
| Звук перелистывания | **Выключен** | Большинство пользователей не хотят |
| Анимации | **Включены, System reduced motion** | Accessibility |
