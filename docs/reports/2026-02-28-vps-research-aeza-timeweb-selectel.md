# Исследование VPS/VDS: Aeza, Timeweb Cloud, Selectel

**Дата:** 28 февраля 2026
**Цель:** Найти VPS/VDS сервер 8-12 ядер, 24-32 ГБ RAM, 50-100 ГБ NVMe, бюджет 7000-10000 руб/мес
**Методология:** Веб-поиск по официальным сайтам, обзорным порталам (easylinklife.com, hosters.ru, hostings.info, hosting.country, dtf.ru, vc.ru), вики-базам провайдеров, PDF-прайслистам
**Ограничения:** Точные цены конфигуратора Selectel и Aeza (dedicated) не удалось получить без интерактивного доступа к калькуляторам. Цены Timeweb Cloud основаны на прайс-листе от 04.06.2024 и могли измениться.

## 1. Aeza (aeza.ru)

### 1.1. Общая информация

Aeza -- международный облачный провайдер, работающий с 2019 года. Более 4400 активных серверов. Для российских клиентов есть отдельная версия сайта aeza.ru с ценами в рублях (выгоднее, чем конвертация с aeza.net в евро). Позиционируется как провайдер с акцентом на производительность и современное оборудование.

### 1.2. Оборудование и виртуализация

| Параметр                  | Значение                                               |
| ------------------------- | ------------------------------------------------------ |
| **Процессоры**            | AMD Ryzen 9 9950X, Threadripper 3990X, Intel i9 14900K |
| **Виртуализация**         | KVM                                                    |
| **Диски**                 | NVMe SSD с RAM-cache                                   |
| **Nested virtualization** | Включена (важно для Docker-in-Docker)                  |

### 1.3. Тарифы VPS (Москва)

#### Shared vCPU (общие ядра)

| Тариф             | vCPU | RAM   | Диск NVMe | Цена/мес   |
| ----------------- | ---- | ----- | --------- | ---------- |
| Shared-1          | 1    | 2 ГБ  | 30 ГБ     | 593 руб    |
| ...               | ...  | ...   | ...       | ...        |
| Shared-8 (прибл.) | 8    | 16 ГБ | 240 ГБ    | ~4 746 руб |
| Shared-16         | 16   | 32 ГБ | 480 ГБ    | 9 491 руб  |

**ВАЖНО:** Shared-тарифы используют общие ядра CPU. Для production-проекта с AI-обработкой книг **не рекомендуются** -- CPU будет делиться с соседями.

#### Dedicated vCPU (выделенные ядра)

| Тариф       | vCPU | RAM  | Диск NVMe | Цена/мес |
| ----------- | ---- | ---- | --------- | -------- |
| Dedicated-1 | 1    | 2 ГБ | 30 ГБ     | 849 руб  |
| ...         | ...  | ...  | ...       | ...      |

**Точные цены на Dedicated с 8+ ядрами не удалось найти в открытых источниках.** Ориентировочно, если экстраполировать пропорцию shared/dedicated (~1.43x), Dedicated 8c/16GB/240GB будет стоить ~6 800 руб, а 16c/32GB/480GB -- ~13 600 руб. **Эти цифры -- оценка, не подтверждённая цена.**

#### Специализированные линейки

### 1.4. Конфигуратор (кастомная сборка)

**Есть.** Aeza позволяет:

- Добавлять ресурсы поштучно (ядра, RAM, диск) к любому тарифу
- Масштабировать без простоев (hot resize)
- Переключаться между тарифами через панель управления

Точные цены за единицу ресурса при кастомной сборке не опубликованы в открытом доступе.

### 1.13. Оценка для проекта fancai

**Оптимальная конфигурация:** Dedicated 8 vCPU / 16 ГБ RAM / 240 ГБ NVMe

- **Ориентировочная цена:** ~6 800 руб/мес (оценка, точную цену нужно проверить на сайте)
- **Проблема:** 16 ГБ RAM может быть мало (нужно 24-32 ГБ). Для 24+ ГБ потребуется кастомная конфигурация через конфигуратор или тариф 16c/32GB

**Плюсы:**

- Мощные процессоры Ryzen 9 9950X
- Бесплатная DDoS-защита 2 Тбит/с
- Безлимитный трафик
- Бесплатные бэкапы
- Hot resize без миграции
- Удобные способы оплаты

**Минусы:**

- SLA всего 99.8% (самый низкий)
- Непрозрачные цены на Dedicated тарифы с 8+ ядрами
- Жалобы на скорость техподдержки
- Относительно молодой провайдер (с 2019)

Selectel -- один из крупнейших и старейших российских провайдеров инфраструктуры (с 2008 года). **Собственные дата-центры** (не арендует у третьих лиц). Позиционирование: корпоративный уровень, enterprise-grade инфраструктура. Публичная компания с прозрачной отчётностью.

### 3.2. Оборудование и виртуализация

| ----------------------- | ------------------------------------------ |

| **Линейки**             | Standard, Compute, Memory-Optimized, и др. |
| **Shared vs Dedicated** | Обе опции (базовые и выделенные ядра)      |

### 3.3. Тарифы облачных серверов

- Конфигурация 8 vCPU / 24 ГБ RAM -- допустима (1:3)

#### Расчёт конфигурации для проекта (оценка)

Исходя из стоимости Standard 1 vCPU/1 ГБ = 1 162 руб/мес, прямая экстраполяция невозможна (цена не линейна). Однако, основываясь на доступных данных:

- **8 vCPU / 24 ГБ (выделенные ядра):** Ориентировочно **8 000-12 000 руб/мес** (возможно выше бюджета)
- **8 vCPU / 24 ГБ (базовые/shared ядра):** Дешевле, но не подходит для production AI-нагрузки

**Точную цену невозможно указать без использования калькулятора на сайте.** Selectel -- наиболее дорогой из трёх провайдеров.
