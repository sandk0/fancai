## Среднесрочные задачи (Приоритет: Средний)

### 4. Унификация навигации для всех платформ
**Оценка:** 2-3 часа

Сейчас `directScroll()` используется только на iOS/Android. Рассмотреть:
- Использование измерения из DOM для всех платформ
- Убрать условие `if (isIOS() || isAndroid())` в `nextPage()`/`prevPage()`
- Единая логика навигации

### 5. Улучшение обработки границ глав
**Оценка:** 1-2 часа

Текущая логика:
```typescript
if (direction === 'next' && currentScroll >= maxScroll - 1) {
  return false; // Let epub.js handle chapter change
}
```

Возможные улучшения:
- Предзагрузка следующей главы
- Визуальная индикация конца главы
- Плавный переход между главами

### 6. Кэширование результатов измерения
**Оценка:** 1 час

`getMeasuredScrollUnit()` вызывается при каждом свайпе. Можно:
- Кэшировать результат на время главы
- Инвалидировать кэш при resize или смене главы
- Уменьшить нагрузку на DOM queries

## Долгосрочные задачи (Приоритет: Низкий)

### 7. Поддержка RTL (Right-to-Left) книг
**Оценка:** 4-6 часов

Текущий код не учитывает RTL направление текста:
- Свайп влево = следующая страница (для LTR)
- Для RTL должно быть наоборот
- Нужно проверить `book.package.metadata.direction`

### 8. Адаптивное поведение при изменении ориентации
**Оценка:** 2-3 часа

При повороте устройства:
- Пересчёт scroll unit
- Сохранение текущей позиции
- Плавная адаптация layout

### 9. Поддержка multi-touch жестов
**Оценка:** 3-4 часа

Дополнительные жесты:
- Pinch-to-zoom для изображений
- Двойной тап для увеличения
- Свайп двумя пальцами для быстрой навигации
