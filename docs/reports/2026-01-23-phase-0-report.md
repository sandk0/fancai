# Отчет о выполнении Фазы 0: База Данных и Схема

**Дата:** 23 января 2026
**Статус:** Выполнено (Миграция создана)

## Выполненные работы

В рамках подготовки фундамента для v16 архитектуры были внесены следующие изменения в структуру базы данных:

### 1. Модернизация модели `Entity`
В файл `backend/app/models/entity.py` добавлены новые поля:
-   **`importance` (Integer, 1-10)**: Поле для хранения оценки сюжетной важности персонажа/локации. Это ключевой элемент для "Gatekeeper Logic" (фильтрации мусора).
-   **`linked_entity_ids` (JSONB)**: Поле для хранения массива ID связанных сущностей (для ассетов и медиа-галереи).

### 2. Создание таблицы Графа (`EntityRelationship`)
Создан новый файл `backend/app/models/entity_relationship.py`, реализующий паттерн **Adjacency List**.
-   Таблица: `entity_relationships`
-   Поля: `source_id`, `target_id`, `type` (KINSHIP, ALLY, ENEMY), `weight` (-100..100).
-   Индексы: Создан композитный индекс `idx_source_type` для быстрого поиска связей (например, "все друзья Гарри").

### 3. Миграции
Из-за ограничений среды выполнения (отсутствие установленного `alembic` в CLI контейнера), файл миграции был создан вручную.
-   **Файл:** `backend/alembic/versions/2026_01_23_0001_v16_schema_upgrade.py`
-   **Содержание:** Инструкции `upgrade()` для добавления колонок и создания таблицы, а также `downgrade()` для отката.
-   **Действие пользователя:** Необходимо выполнить `alembic upgrade head` на сервере для применения изменений.
