# Архив документации

Эта директория содержит исторические `.md`-документы, которые перестали отражать
текущее состояние проекта, но сохранены для исторической справки.

**Не редактируйте файлы здесь.** Если документ нужно актуализировать — переписывайте
его в основной директории `docs/` с современным контекстом, не правьте архив.

## Структура

- `development/` — устаревшие отчёты, планы и анализы из `docs/development/`
  (октябрь–ноябрь 2025): early-stage planning, EPUB-reader analyses, agent-system
  documents, performance/testing рефакторинг-аудиты.
- `DEVELOPMENT_PROGRESS.md` (август 2025) — самый ранний прогресс-снапшот.
- `FRONTEND-AUDIT.md` (март 2026) — frontend-аудит, факты вошли в `.planning/STATE.md`.
- `IMAGE-GENERATION-BUGS-AUDIT.md` (март 2026) — image-генерация баг-аудит, ушёл в Phase 27/28.
- `AUDIT-2026-03-21-session-fixes.md` — конкретные сессионные фиксы марта.

## Когда смотреть в архив

- Реконструируете контекст решения, принятого до 2026-04
- Изучаете эволюцию фичи (например, EPUB reader декомпозиция)
- Ищете обоснование, почему что-то сделано определённым образом

## Когда **не** смотреть

- Нужна актуальная информация о стеке, командах, AI-моделях — это `README.md`,
  `docs/README.md`, `.planning/PROJECT.md`
- Нужны актуальные milestone-данные — `.planning/MILESTONES.md`,
  `.planning/STATE.md`, `.planning/ROADMAP.md`
- Нужны исторические отчёты по фазам — `docs/reports/` (тоже архив, но с
  чёткой датировкой)
