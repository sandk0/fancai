## Контекст проекта (для понимания)

fancai — веб-приложение для чтения книг с AI-функциями (entity wiki, генерация иллюстраций). Production на fancai.ru. Стек: React 19 + FastAPI + PostgreSQL + Redis + Celery. AI: Modal (vLLM Qwen3.5-9B на L40S GPU) для entity extraction + OpenRouter (Gemini 3.0 Flash) как fallback.

Milestone v1.5 фокусируется на стабилизации сломанного Modal pipeline (10/23 глав падают) и переходе от sequential per-chapter обработки к chunked sub-batch. Ожидаемый эффект: 7-13x ускорение, $3.48 → $0.26-0.49 за книгу.

GSD (Get Shit Done) — фреймворк планирования, используемый в проекте. Он автоматически разбивает работу на фазы, требования, планы.
