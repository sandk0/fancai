## Средняя книга (baseline)

| Параметр          | Значение | Обоснование                                   |
| ----------------- | -------- | --------------------------------------------- |
| Глав в книге      | **25**   | Медиана для художественной литературы (роман) |
| Символов в главе  | ~20,000  | Средний размер главы                          |
| Символов в книге  | ~500,000 | 25 × 20K                                      |
| Сущностей в книге | ~80-150  | Персонажи + локации + объекты                 |
| Описаний на главу | ~3-8     | Визуальные описания для иллюстраций           |

| **Полная обработка книги (25 глав)** | **75-125**   | **$0.50-1.50** |
