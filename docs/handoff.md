### Четыре вещи, на которые следующая сессия наступит, если не прочитать

1. **PageRank не работает, и это не регрессия S4.** `nx.pagerank` в networkx 3.6
   требует `scipy`, а `scipy` не стоит ни в одном из проверенных образов.
   До удаления GLiNER в celery-образ через `torch` приезжал `numpy` — но не
   `scipy`, поэтому `calculate_pagerank()` падал и тогда, только с другим текстом
   ошибки. Значит `Entity.importance` PageRank'ом не обновляется — проверено
   на pre-S4 baseline и на текущем коде; всю историю образов не поднимали.
   Соседний `detect_communities` мёртв по той же причине: `import community`
   (`python-louvain`) отсутствует в зависимостях. Решение — отдельное: либо
   поставить `scipy` (+≈35 МБ и **изменение значений `importance` на живых
   данных**), либо выкинуть графовую фазу.
2. **Отказ пост-фазы больше не роняет книгу, но причина осталась.**
   `calculate_pagerank()` при исключении делает `db.rollback()`, а rollback
   экспайрит ORM-объекты сессии. Раньше это валило `_finalize_book_status()`
   по `MissingGreenlet` уже после разбора всех глав: книга оставалась
   с `is_processing=true`, задача Celery падала. Сейчас книга перечитывается
   через `db.get()` перед финализацией — но **любой другой код, который держит
   ORM-объект через пост-фазы, наступит на то же самое**.
3. **Повторная сущность без алиасов роняет главу.** Upsert
   в `consistency_manager._batch_resolve_entities` считает `aliases_with_reveal`
   через `jsonb_agg` по объединению старого и нового массивов; если оба пусты,
   агрегат возвращает NULL, а колонка `NOT NULL`. Любая сущность, встреченная
   в двух главах и ни разу не получившая алиас, обрушивает вторую главу
   с `NotNullViolationError`. Воспроизводится первым же прогоном smoke без
   алиасов в фикстуре. Фикс — одна строка (`COALESCE(jsonb_agg(...), '[]'::jsonb)`),
   но он вне объёма S4 и требует своего теста.
4. **`frontend/.env.development` протух.** `VITE_API_BASE_URL=http://localhost:8000`
   без `/api/v1`, поэтому `npm run dev` из коробки бьётся в 404 на `/auth/login`.
   Обход на время сессии — `VITE_API_BASE_URL=/api/v1 npm run dev` (тогда работает
   прокси Vite). Файл трекается и в 25 чужих не входит — можно чинить.

### Семь багов, найденных вживую и исправленных

Первые три — продовые, найдены обязательным smoke Волны 6 и старше неё.

1. **Потеря файла при перегенерации изображения.**
   `ImageCRUDService.update_after_regeneration()` удалял старый файл **до** коммита.
   На cache hit `ImagenService` отдаёт `image_url` как `data:image/png;base64,…`
   и `local_path=None`, а колонка — `VARCHAR(2000)`: коммит падал, rollback возвращал
   прежний путь в БД, файла по нему уже не было. Триггер массовый: ключ кэша не
   учитывает `custom_style`, поэтому «перегенерировать с другим стилем» **всегда**
   попадает в кэш. Удаление перенесено за успешный коммит, то же в `delete_with_file()`.
2. **Учёт расходов терялся в Celery-тасках.** `llm_usage_log` писался через
   `asyncio.create_task()`, а таски идут через `run_async()` → `asyncio.run()`,
   который на выходе отменяет незавершённые задачи. Заменено на `await`
   в пяти call sites обоих клиентов (Gemini `_log` и image, OpenRouter text,
   structured и image).
3. **Все иллюстрации генерировались не в том соотношении сторон.**
   `GeminiClient.generate_image()` принимал `aspect_ratio`/`image_size`, но не клал
   их в `types.ImageConfig`. Продовый путь просит `4:3`/`1K`, получал 16:9. Заодно
   врал учёт: `compute_image_cost` берёт запрошенный размер.
   После фикса: `4:3` → 1200×896, `16:9` → 1376×768, `1:1`+`2K` → 2048×2048.
4. **CORS ломал каждый GET в dev-режиме.** `frontend/src/api/client.ts` слал
   `Pragma` и `Expires`, которых нет в `allow_headers` бэкенда: preflight
   отклонялся, любой GET с `localhost:5173` падал с `net::ERR_FAILED`. В проде
   не проявляется — Caddy отдаёт SPA и API с одного origin. Это же снимает
   прошлую находку «библиотека не рефетчит список книг».
5. `MobilePanel` сбрасывал снап-точку на каждом рендере (эффект зависел от
   литерала массива `snapPoints`).
6. `DescriptionDrawer` повторял побочные эффекты завершения задачи при
   переоткрытии drawer.
7. `useReaderPosition` держал два источника истины для флага восстановления.

Пункты 1–3 закрыты тестами, проверенными мутацией: с откаченным фиксом тест падает
(`test_image_crud_file_safety.py`, `test_usage_is_persisted_when_call_runs_under_asyncio_run`,
`test_generate_image_passes_aspect_ratio_and_size_to_sdk`). Пункты 4–7 —
фронтенд: проверены зелёным `npm run lint` при `--max-warnings 0`, полным
`npm test` (566/1) и живым проходом по UI, отдельными мутационными тестами
не закрывались.

### Не исправлено: контракт кэша изображений сломан целиком

Пункт 1 выше убрал **потерю файла**, но не починил cache hit. `ImagenService`
кладёт в Redis сам `data:image/png;base64,…` (мегабайты) и на hit возвращает его
в `image_url`, не отдавая `local_path`. Все шесть потребителей выводят сохраняемый
URL только из `local_path`, поэтому на cache hit:

| Место | Что происходит на cache hit |
| --- | --- |
| `tasks/image_tasks.py:167` (single) | строка `generated_images` со `status='completed'` и `image_url=NULL` |
| `tasks/image_tasks.py:376` (batch) | то же |
| `routers/images.py:396` (sync generate) | то же |
| `routers/images.py:506` (sync batch) | то же |
| `routers/images.py:716` (regenerate) | **HTTP 500**: data-URI не влезает в `VARCHAR(2000)`. Файл теперь цел, но запрос падает |
| `services/consistency_manager.py:527` (master reference) | `master_portrait_url` молча не выставляется, ошибки нет |

Плюс ключ `md5(description + aspect_ratio)` игнорирует `description_type`, `genre`,
`custom_style` и `GEMINI_IMAGE_MODEL`. Починка — это выбор контракта (что кэшируем,
чем ключуем, создаёт ли hit новую строку), поэтому вынесена отдельной задачей.
Ограничение для будущей правки: `delete_with_file()` удаляет файл по `local_path`,
так что переиспользовать один путь в нескольких строках нельзя. Подробности —
в `docs/architecture/ai-pipeline.md`, раздел «Image storage».

### Пять находок, определяющих дальнейшие действия

1. **Прод раздаёт фронтенд-артефакт возрастом ~4 месяца с недоказуемым происхождением.**
   Volume `app_frontend_build` создан 2026-03-29, образа фронтенда нет, OCI-меток нет.
   Checkout при этом на `a1f89900` от 2026-06-16.
2. **`prometheus-fastapi-instrumentator==7.1.0` пинит `starlette<1.0.0`** и в одиночку
   удерживает 5 неисправленных CVE в starlette 0.52.1. Лечится группой
   fastapi 0.141.1 + instrumentator 8.1.0.
3. **Четыре прямых пина бэкенда не используются кодом** (`pillow`, `ecdsa`,
   `python-decouple`, `python-dateutil`); первые два несут 20 уникальных advisory.
4. **`overrides.brace-expansion` во фронтенде вреден**: сам уязвим и ломает API
   `glob@11`, из-за чего Workbox генерирует пустой precache.
5. **`OPENROUTER_IMAGE_MODEL` указывает на несуществующую модель** — FLUX полностью
   отсутствует в каталоге OpenRouter. Путь отката для картинок нерабочий.
   Отдельно: `FALLBACK_MODELS` (2.5-семейство) выключается Google **2026-10-16**.
