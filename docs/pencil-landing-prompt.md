# Промпт для Pencil.dev — лендинг fancai

## Контекст для работы

Pencil.dev — MCP-canvas внутри IDE. Промпт подаётся через AI-чат (Claude Code с моделью Opus 4.6). Pencil генерирует дизайн на канвасе в формате .pen, затем экспортирует в React + Tailwind CSS код.

## Промпт (скопировать целиком в AI-чат Pencil)

---

Спроектируй одностраничный промо-лендинг для продукта «fancai» — мобильного AI-ридера книг. Лендинг должен быть ярким, современным, запоминающимся и с обилием плавных анимаций. Главная задача лендинга — влюбить посетителя в продукт, наглядно показать как он работает и мотивировать зарегистрироваться. Язык контента — русский. Лендинг должен быть адаптивным (desktop-first, но корректно выглядит на мобильных).

Удиви меня оригинальным дизайном. Я не задаю стили, цвета, типографику или дизайн компонентов — это полностью на твоё усмотрение. Покажи высший уровень креатива.

### О продукте

fancai (fancai.ru) — PWA-приложение, AI-ридер книг с двумя уникальными AI-функциями:

1. **Entity Wiki** — AI анализирует книгу и строит живой глоссарий персонажей, локаций и объектов. Глоссарий привязан к прогрессу чтения — пользователь никогда не увидит спойлеров дальше текущей главы. Имена персонажей кликабельны прямо в тексте книги.

2. **AI-иллюстрации** — AI находит в тексте визуальные описания (локации, сцены, персонажи) и генерирует уникальные иллюстрации к ним. Пользователь тапает на подсвеченное описание в тексте → видит сгенерированную иллюстрацию.

Дополнительные фичи: жестовая навигация с follow-finger анимацией как в Apple Books (свайпы + тапы по краям), 5 тем оформления (светлая, тёмная, сепия, ночная AMOLED, дневная), закладки и заметки с цветовым выделением текста, оффлайн-чтение, полноценная PWA с установкой на домашний экран. Приоритетный контент — русскоязычные книги.

Целевая аудитория: активные читатели 20–45 лет, которые хотят более глубокого погружения в книгу.

### Структура лендинга (секции сверху вниз)

**1. Hero-секция**

Главный экран, который видит посетитель. Сильный заголовок, передающий идею: AI понимает книгу вместе с вами — показывает персонажей, рисует иллюстрации, не спойлерит. Короткий подзаголовок с эмоциональным описанием ценности. Две CTA-кнопки: основная «Начать читать бесплатно» и вторичная «Узнать больше» (скролл вниз). В hero-секции — центральный визуальный элемент: крупный мокап телефона, показывающий приложение в действии (экран ридера с открытой книгой, подсвеченные описания в тексте). Мокап телефона должен выглядеть объёмно и привлекательно — с наклоном, тенями, свечением. Анимация: мокап плавно появляется с параллаксом при скролле, текст и кнопки fade-in с задержкой.

**2. Секция «Как это работает» — 3 шага**

Визуальная цепочка из трёх шагов:
- Шаг 1: «Загрузите книгу» — иконка + короткое описание (EPUB/FB2, drag-and-drop). Рядом — мини-мокап телефона, показывающий экран загрузки.
- Шаг 2: «AI анализирует текст» — иконка + описание (находит персонажей, описания, строит глоссарий). Мини-мокап с entity wiki drawer.
- Шаг 3: «Читайте с AI-компаньоном» — иконка + описание (иллюстрации, wiki без спойлеров, заметки). Мини-мокап с ридером и AI-иллюстрацией.

Между шагами — анимированные соединительные линии или стрелки. Каждый шаг появляется при скролле (stagger animation). Мокапы телефонов — ключевой визуальный элемент, показывающий реальное приложение.

**3. Секция «Entity Wiki — AI-глоссарий без спойлеров»**

Подробный showcase первой ключевой фичи. Слева — крупный мокап телефона с экраном Entity Wiki: список персонажей с аватарами, типами (персонаж/локация), краткими биографиями. Справа — текстовое описание фичи: AI анализирует книгу глава за главой, строит живой глоссарий, биографии обновляются по мере прочтения, никаких спойлеров. Акцентировать: «Забыли кто такой этот персонаж? Тапните на его имя прямо в тексте». Анимация: мокап плавно выезжает слева, текст справа — при скролле. При hover или через интервал — внутри мокапа анимированный переход: список сущностей → карточка персонажа с биографией.

**4. Секция «AI-иллюстрации к каждому описанию»**

Showcase второй ключевой фичи. Layout зеркальный предыдущей секции — текст слева, мокап справа. В мокапе — экран ридера, где в тексте подсвечено описание, и снизу выезжает bottom sheet (drawer) с AI-сгенерированной иллюстрацией. Текст описывает: AI находит визуальные описания (пейзажи, внешность, интерьеры), генерирует иллюстрации в один тап, можно перегенерировать, все иллюстрации сохраняются в галерею. Анимация: при скролле мокап появляется, внутри мокапа — анимация «подсвеченный текст → тап → drawer выезжает снизу с иллюстрацией».

**5. Секция «Чтение, которое хочется»**

Bento grid (сетка карточек разного размера) с дополнительными фичами:
- Карточка «Жесты как в Apple Books» — мини-демо свайпа страницы с follow-finger анимацией. Мокап телефона с анимацией перелистывания.
- Карточка «5 тем оформления» — 5 круглых превью тем (светлая, тёмная, сепия, ночная, дневная). При hover/интервале — мокап ридера меняет тему.
- Карточка «Закладки и заметки» — иконка + описание, мини-мокап с цветным выделением текста и tooltip.
- Карточка «Оффлайн-чтение» — иконка облака/офлайн + описание. PWA, работает без интернета.
- Карточка «Поиск по книге» — мини-мокап с панелью поиска.
- Карточка «Статистика чтения» — мини-мокап с графиками и streak.

Анимация: карточки появляются с масштабированием (scale up) и stagger delay при скролле. На каждой карточке — subtle hover-эффект (приподнимание + тень).

**6. Секция «Галерея иллюстраций»**

Горизонтальная прокрутка или masonry-grid с примерами AI-иллюстраций. 6–8 красивых примеров иллюстраций (placeholder-изображения из картинок книг — фэнтези-пейзажи, портреты персонажей, интерьеры). Под каждой иллюстрацией — короткая цитата-описание из книги, по которой она была сгенерирована. Анимация: бесконечная автопрокрутка или карусель. При hover — масштабирование карточки.

**7. Секция «Живая демонстрация» (интерактивная)**

Интерактивная секция, которая воспроизводит опыт чтения прямо на лендинге. Центральный крупный мокап телефона (или iframe-подобный контейнер) в котором показан текст книги с подсвеченными описаниями и кликабельными именами персонажей. Посетитель может: тапнуть на подсвеченное описание → увидеть выезжающий drawer с иллюстрацией, тапнуть на имя персонажа → увидеть bottom sheet с карточкой персонажа, свайпнуть страницу. Это не настоящее приложение — это выверенная анимационная демонстрация, имитирующая реальное взаимодействие. Анимация: все переходы плавные — drawer выезжает снизу, bottom sheet появляется с пружинной анимацией, свайп отвечает follow-finger.

**8. Социальное доказательство / статистика**

Блок с крупными числами-счётчиками: «X книг загружено», «Y иллюстраций создано», «Z персонажей проанализировано». Числа анимированно инкрементируются при попадании секции во viewport (count-up animation). Можно добавить 2–3 цитаты-отзыва пользователей (placeholder-тексты).

**9. Финальный CTA**

Заключительная секция с сильным призывом к действию. Заголовок: что-то вроде «Начните читать по-новому». Подзаголовок: бесплатная регистрация, загрузка первой книги за минуту. Крупная CTA-кнопка «Начать бесплатно». Мягкий фоновый градиент или абстрактная анимация за текстом.

**10. Футер**

Минимальный футер: логотип, копирайт, ссылки (О проекте, Поддержка, Политика конфиденциальности). Иконки соцсетей (Telegram-канал).

### Требования к анимациям

Анимации — ключевой элемент лендинга. Общие принципы:

- Все секции появляются при скролле (scroll-triggered) с плавным fade-in + translate. Используй stagger delay для элементов внутри секции.
- Мокапы телефонов — главные визуальные якоря. Они должны появляться эффектно (с лёгким наклоном, параллаксом, тенью). Внутри мокапов — живые анимации, имитирующие работу приложения (переключение экранов, выезжающие panels, смена тем).
- Hero-секция: мокап телефона появляется с 3D-эффектом (наклон perspective), текст — каскадный fade-in.
- Плавные переходы между секциями — используй gradient dividers или wave-shaped разделители, а не жёсткие линии.
- Числа в секции статистики — count-up анимация при попадании во viewport.
- Карусель иллюстраций — автопрокрутка или parallax.
- Кнопки — hover-эффект с масштабированием и мягкой тенью.
- Общий ритм: анимации быстрые (200–400ms), easing — ease-out или spring. Не перегружать — каждая анимация должна направлять внимание, а не отвлекать.

### Мокапы телефонов — что внутри

Мокапы телефонов (phone mockups) — важнейший визуальный элемент лендинга. Они показывают реальный интерфейс приложения. Вот что рисовать внутри каждого:

- **Ридер:** белый/тёмный фон, текст книги (2–3 абзаца русского текста), в тексте — 1–2 подсвеченных фрагмента (описание с цветным фоном), 1–2 кликабельных имени персонажа (другой цвет). Внизу — тонкая полоска прогресса чтения. Сверху — полупрозрачная шапка с кнопкой назад, заголовком книги и иконками (wiki, поиск, настройки).
- **Entity Wiki:** список из 5–6 карточек сущностей. Каждая — аватар-кружок с иконкой (человечек/метка/куб), имя сущности, тип (badge «персонаж», «локация»), одна строка описания. Строка поиска вверху.
- **Описание + иллюстрация:** Bottom sheet drawer, выехавший снизу на 60% экрана. Внутри — текст описания (2–3 строки) и ниже — прямоугольник иллюстрации (красивый пейзаж или портрет). Кнопка «Сгенерировать заново».
- **Карточка персонажа (Entity Bottom Sheet):** маленький bottom sheet на 30% экрана. Аватар, имя персонажа, тип, 2 строки биографии, кнопка «Подробнее».
- **Темы:** тот же экран ридера, но в 5 вариантах фона: белый, тёмно-серый, бежево-кремовый, чисто-чёрный, тёплый белый.
- **Загрузка книги:** зона drag-and-drop в центре, иконка файла, текст «Перетащите EPUB или FB2». Ниже — превью загруженной книги (обложка, название, автор).
- **Галерея:** сетка из 6 миниатюр AI-иллюстраций (2×3), фильтры сверху (все / персонажи / локации).
- **Статистика:** карточки с числами (книг: 12, часов: 47, серия: 5 дней), маленький столбчатый график активности.

### Текстовый контент для лендинга (русский)

- Заголовок hero: используй что-то образное, передающее идею «AI-компаньон для чтения», «книги оживают» или «читай глубже с AI».
- Feature descriptions: короткие, ёмкие, 1–2 предложения.
- Текст внутри мокапов ридера: используй фрагмент художественного текста на русском (2–3 абзаца), с несколькими подсвеченными описаниями и именами. Можно придумать или взять нейтральный фэнтези-фрагмент.
- Числа статистики (placeholder): 12 000+ книг загружено, 85 000+ иллюстраций создано, 340 000+ персонажей в wiki.

### Технические заметки

- Результат должен быть экспортирован как один React-компонент (или набор секционных компонентов) с Tailwind CSS.
- Иконки: Lucide React.
- Анимации: Framer Motion (motion/react) или CSS animations/transitions.
- Мокапы телефонов: рисуй средствами CSS/SVG — скруглённые прямоугольники с тенью, обводкой, notch.
- Placeholder-изображения: gradient-блоки или CSS-рисованные абстракции (не внешние URL).
- Адаптивность: desktop-first (1440px max-width), корректный мобильный вид.
