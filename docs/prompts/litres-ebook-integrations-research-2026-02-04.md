## Часть 1: Контекст проекта

### 1.1 О проекте fancai

**fancai** — приложение для чтения художественной литературы с уникальной функцией: AI автоматически извлекает визуальные описания из текста (персонажи, локации, сцены, объекты) и генерирует по ним иллюстрации с помощью нейросетей с сохранением консистентности персонажей и локаций на протяжении всей книги.

**Текущий стек:**
- **Frontend:** React 19 + TypeScript 5.7 + Vite 6 + TailwindCSS
- **Backend:** FastAPI + Python 3.11 + PostgreSQL 15 + Redis 7.4 + Celery
- **AI:** Google Gemini 3.0 Flash (извлечение описаний) + Google Imagen 4 (генерация иллюстраций)
- **Кэширование:** TanStack Query (фронтенд) + IndexedDB/Dexie (офлайн) + Redis (бэкенд)
- **Форматы книг:** EPUB, FB2 (DRM-free файлы до 10 МБ)
- **Аутентификация:** JWT (access + refresh tokens), планируется Sign in with Apple, Google, Telegram

**Ключевая потребность:**
Сейчас пользователь может только вручную загружать книги (EPUB/FB2) через upload. Это неудобно — пользователь вынужден искать файлы книг в интернете, скачивать их и загружать в приложение. Мы хотим дать возможность подключить аккаунты электронных библиотек (ЛитРес, MyBook, Bookmate и др.), чтобы купленные/подписочные книги автоматически подтягивались в библиотеку fancai и были доступны для чтения с AI-иллюстрациями.

### 1.2 Целевая аудитория

- Русскоязычные читатели художественной литературы (основная аудитория)
- Пользователи ЛитРес, MyBook, Bookmate и других книжных сервисов
- Люди, которые читают много книг и ценят визуализацию
- Пользователи в возрасте 18-45 лет, технически грамотные

### 1.3 Существующая архитектура импорта книг

Текущий процесс:
```
Пользователь → Загружает файл (EPUB/FB2) → Backend парсит книгу → Сохраняет в PostgreSQL → Книга доступна для чтения
```

Желаемый процесс:
```
Пользователь → Подключает аккаунт ЛитРес/MyBook/... → fancai получает список книг → Пользователь выбирает книги → fancai скачивает/стримит книги → Книги доступны для чтения с AI-иллюстрациями
```
