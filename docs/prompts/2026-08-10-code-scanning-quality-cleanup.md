## §5. Что вынести владельцу, а не решать самому

34 security-алерта CodeQL остаются открытыми и это **осознанное состояние**:
код по ним санирован и защита доказана мутацией, но CodeQL не признаёт ни
`resolve()/is_relative_to` (path-injection), ни центральный скруббер логов.
Владелец выбирал между «снять с обоснованием» и «дописать до узнаваемого
сканером» — решение не принято.

Важное уточнение, которое надо озвучить, если тема поднимется: перевод
`log-injection` на `extra={...}` **выкинет данные из логов**. Ключи `extra`
ложатся атрибутами на `LogRecord` и попадают в вывод только если их упоминает
format-строка хендлера, а stdlib-путь настраивается `logging.basicConfig()`
из `core/database.py` с дефолтным форматом. Готового потребителя `extra`
в проекте нет — `_serialize_extra` в `core/logging.py` мёртв. Вариант честен
только вместе с настройкой форматтеров.

## §6. Ловушки стенда — знать до первого прогона

- **На push запускаются ДВА workflow** — `ci.yml` и `security.yml`. Зелёный
  `CI/CD Pipeline` не означает зелёный CI. Проверять по SHA:
  `gh run list --json headSha,workflowName,conclusion`.
- **Тестовая БД одна на всех.** Ручной `pytest` во время фонового
  `check-coverage.sh` роняет оба прогона: фикстура `test_db` создаёт и дропает
  `fancai_test` под собой. Прогоны не пересекать.
- **Слово `nosec` в ЛЮБОМ комментарии** bandit разбирает как директиву.
  Пояснения про подавление писать без этого токена.
- **`fancai_postgres_dev` может пропасть посреди сессии** — симптом
  `socket.gaierror: Name or service not known`.
- **Файловые хранилища в тестах** уводятся в `tmp_path` autouse-фикстурой
  `storage_dirs_in_tmp`; новый тест, пишущий файлы, должен брать каталог
  ИЗ МОДУЛЯ, а не через `from ... import CONST`.
- **Порог покрытия живёт в `backend/check-coverage.sh`**, не в `addopts` —
  узкие прогоны безопасны. `concurrency = ["thread", "greenlet"]`
  в `pyproject.toml` **не снимать**: без него всё тело async-endpoint'а ниже
  первого `await` к БД числится непокрытым.
- **Миграции Alembic не править** — они применены.
