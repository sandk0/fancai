## Контекст проекта

**fancai** — веб-приложение для чтения книг с двумя AI-фичами:
1. Генерация иллюстраций (Gemini 3.0 Flash извлекает описания → Imagen 4 генерирует картинки)
2. Entity Wiki — интерактивный глоссарий персонажей/локаций/объектов без спойлеров (основная фича)

**Стек:** React 19 + TypeScript 5.7 + Vite 7 | FastAPI 0.128 + Python 3.11 + PostgreSQL 15/17 + Redis 7.4 + Celery 5.6
**AI:** Gemini 3.0 Flash (~$0.02/книга) | Imagen 4 ($0.04/изображение)
**Продакшен:** https://fancai.ru | VPS 8GB RAM, 4 CPU

**Текущий этап:** Проект в активной разработке 5.5 месяцев (514 Task calls). NLP-система удалена (декабрь 2025), остатки не вычищены. Используется GSD для планирования и выполнения — 6-фазный роадмап создан, Phase 1 (Production Safety) готова к выполнению, ещё не начата.

**Предыдущие аудиты:**
- 2026-02-05: Конфигурация CLAUDE.md (174→48 строк), settings, hooks
- 2026-02-06: Полный аудит проекта (7 агентов, 551K токенов) — обнаружены: chunk boundary entity loss, spoiler-free untested, router files 30-40K LOC
