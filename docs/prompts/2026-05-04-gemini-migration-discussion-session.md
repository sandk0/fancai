## Формат обсуждения

**Идём строго по структуре документа сверху вниз.** В каждой сессии разбираем 1-3 раздела максимум, с глубокой проработкой деталей. Не пытайся обсудить весь план сразу — он слишком большой.

**На каждом пункте/этапе:**

1. **Начни с краткого резюме** что предлагает план в этом разделе (3-5 строк, без копирования)
2. **Подсвети открытые вопросы** для этого раздела (из секции Open Questions, или которые ты сам видишь)
3. **Выдели риски и trade-offs** — кратко, без duplicating аудита
4. **Задай конкретные вопросы мне** — по одному, ждать ответа на каждый
5. **После моего ответа — зафиксируй решение** одной-двумя строками, перед переходом к следующему вопросу

**Не делай:**
- Не пиши код пока я явно не попрошу
- Не предлагай сразу несколько решений на каждый вопрос — я хочу опираться на свою интуицию, а ты помогаешь её проверить
- Не пропускай вопросы которые кажутся "очевидными" — часто там скрыты gotchas
- Не возвращайся к решениям из секции "Ключевые решения" выше без явного триггера с моей стороны

**Стиль ответов:**
- Краткие, ориентированные на действие. Без длинных вступлений
- Заголовки и таблицы где помогают
- Подсвечивай non-obvious нюансы insights
- Подтверждай мои решения через **Why:** + **How to apply:** где это что-то меняет в плане
- Используй russian terminology, английские identifier и code оставляй как есть

## Пояснения к промпту (это вне промпта, для меня самого)

### Почему такой формат

1. **Self-contained:** новая сессия не имеет контекста — все ключевые решения и пути к файлам нужно повторить
2. **Anti-rabbit-hole:** «1-3 раздела за сессию» предотвращает попытку обсудить всё сразу и потеряться
3. **Q&A discipline:** «по одному вопросу, ждать ответа» — соответствует profile разработчика (fast-intuitive decisions, hypothesis-driven debugging — он хочет проверять свои гипотезы, не получать готовые решения)
4. **Persistent progress:** файл `*-discussion-progress.md` сохраняет state между сессиями
5. **Anti-regression:** «Ключевые решения, уже принятые» защищает от того, что новая сессия начнёт переоткрывать обсуждённое
6. **Russian language preserved:** соответствует CLAUDE.md правилам (`gsd-russian.md`)

### Что делает промпт мощным

- Указание ровно на 1521-строчный главный документ + 4-5 контекстных файлов = достаточный контекст без перегрузки
- Чётко обозначены границы: что обсуждаем, что нет, что already decided
- Стартовая последовательность — модель сразу знает с чего начинать (summary → ask → discuss)
- Format ответов attached к profile разработчика
