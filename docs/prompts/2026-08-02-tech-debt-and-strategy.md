### B. Стратегические решения — с интерактивным обсуждением

**Обсудить нужно все пять, по очереди S1 → S5.** Пропускать пункты нельзя: даже
если решение окажется «не делаем», оно должно быть принято явно и записано.
По каждому: сначала собрать факты по коду, затем разложить варианты с ценой,
дождаться решения. Реализация — только после отдельного решения по этому
конкретному пункту; часть из них §2 запрещает реализовывать в этой сессии
вообще, и это нормально — их результат в том, что решение принято и записано.

| # | Тема | Что нужно решить |
| --- | --- | --- |
| S1 | **Контракт кэша изображений** (`ai-pipeline.md`, раздел «Image storage») | В Redis кладётся data-URI целиком; ключ `md5(description + aspect)` без `description_type`, `genre`, `custom_style`, модели; на hit шесть потребителей ведут себя по-разному, regenerate отдаёт HTTP 500.
