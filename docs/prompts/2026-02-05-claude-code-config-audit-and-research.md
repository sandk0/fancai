## Контекст проекта

**fancai** — full-stack PWA для чтения художественной литературы с двумя ключевыми AI-функциями:

1. **AI-генерация изображений** — LLM извлекает визуальные описания из текста книги, затем генерирует иллюстрации по ним
2. **Глоссарий/Вики по книге (основная продающая функция)** — LLM автоматически строит интерактивную энциклопедию книги: карточки сущностей (персонажи, локации, объекты, события) с описаниями, связями между ними и привязкой к главам. Пользователь может в любой момент чтения открыть карточку персонажа и увидеть всё, что о нём известно к текущей главе (без спойлеров)

- **Frontend:** React 19 + TypeScript 5.7 + Vite 6 + epub.js 0.3.93 + TanStack Query 5 + Zustand 5 + Tailwind CSS 3.4 + shadcn/ui
- **Backend:** FastAPI 0.125 + Python 3.11 + PostgreSQL 15 + Redis 7.4 + Celery 5.4 + SQLAlchemy 2.0
- **AI:** Google Gemini 3.0 Flash (извлечение описаний + построение глоссария) + Google Imagen 4 (генерация изображений)
- **Деплой:** Docker Compose на VPS (fancai.ru), SSH-деплой
- **Продакшен:** https://fancai.ru

### Статистика использования Claude Code (за 5.5 месяцев)

- 654 промпта, 63 сессии, 7 182 вызова инструментов, 685 коммитов (411 co-authored by Claude)
- **59% fix-коммитов** (405 из 685) — главная проблема
- **97 сжатий контекста** за 641 час — марафонские сессии
- **0.7% test-коммитов** (5 из 685) — тестирование почти отсутствует
- Среднее 11 tool calls на промпт — высокая автономность
- Самый изменяемый файл: EpubReader.tsx (84 изменения)
- 48.6% коммитов в ночное время (00-06 МСК)

### Для аудита выяви:

1. **Дублирование** — одна и та же информация в CLAUDE.md, skills, agents
2. **Конфликты** — противоречивые инструкции между компонентами
3. **Мёртвый код** — ссылки на несуществующие компоненты (агенты, skills, MCP)
4. **Избыточность** — настройки, которые Claude может вывести из кода
5. **Пробелы** — критически важная информация, которая нигде не задокументирована
6. **Безопасность** — опасные permissions (SSH, rm, docker exec без ограничений)
7. **Производительность** — влияние каждого компонента на размер контекстного окна (используй данные из `/context`)
