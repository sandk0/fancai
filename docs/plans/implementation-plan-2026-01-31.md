## Полный список изменений (Release Notes)

### 1. Читалка и PWA (Фаза 1)
- **Fix:** Добавлен POST endpoint для Beacon API (`/reading-sessions/{id}/end-beacon`) — надежное сохранение прогресса при закрытии вкладки.
- **Fix:** `useRenditionHealthGuard` теперь учитывает состояние `isResuming` — предотвращает вечный цикл перезагрузок при медленном интернете.
- **Fix:** PWA Resume Guard (overlay вместо unmount) для предотвращения крашей epub.js на iOS.

### 2. LLM и Генерация (Фазы 2, 3, 5)
- **Feature:** Сняты ограничения на количество сущностей (Top-15 → ALL).
- **Feature:** Умное слияние дубликатов (Entity Resolution) с сохранением контекста.
- **Feature:** **Model Tiering** для оптимизации расходов:
  - `gemini-3-flash-preview` для сложных задач (извлечение, анализ)
  - `gemini-2.0-flash-lite` для простых задач (перевод)
- **Quality:** Улучшен промпт перевода для Imagen 4 — добавлены "camera terms" (cinematic lighting, depth of field) для повышения фотореалистичности.

### 3. Защита от спойлеров (Фаза 4)
- **Backend:** В БД добавлены поля `aliases_with_reveal` и `first_mention_chapter`.
- **API:** Фильтрация алиасов ("Избранный", "Дарт Вейдер") в зависимости от текущей главы пользователя.
- **Frontend:** Бейдж "Появление: Глава N" в профиле персонажа.

### 4. Мониторинг (Фаза 5)
- **Prometheus:** Новые метрики для LLM пайплайна:
  - `llm_descriptions_extracted_count`
  - `llm_visual_summary_length_chars`
  - `llm_cache_hits_total` / `misses`

## Фаза 6: QA и стабилизация (Следующий шаг)

Система полностью готова к ручному тестированию.

### Checklist для QA:

1. **Читалка (Mobile/PWA):**
   - [ ] Открыть книгу, свернуть приложение на 30 сек, развернуть. Ожидается: перезагрузка страницы (Health Guard) и корректное восстановление позиции.
   - [ ] Выключить интернет, перелистнуть страницу, закрыть вкладку. Ожидается: Beacon API отправит прогресс (если сеть появится) или сохранит в localStorage.

2. **AI Генерация:**
   - [ ] Загрузить новую EPUB книгу.
   - [ ] Проверить логи: должны использоваться разные модели (`gemini-3` для extract, `gemini-2-lite` для translation).
   - [ ] Проверить качество картинок: должны быть более "кинематографичными".

3. **Спойлеры:**
   - [ ] Открыть профиль персонажа, который раскрывает свое истинное имя в конце книги.
   - [ ] Убедиться, что алиас скрыт, если текущая глава меньше `reveal_chapter`.
