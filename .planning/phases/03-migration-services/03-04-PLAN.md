1. Создать `Caddyfile` в корне проекта (рядом с docker-compose файлами). Использовать паттерн из RESEARCH.md:

```caddyfile
{
    email admin@fancai.ru
}

fancai.ru {
    # Сжатие
    encode zstd gzip

    # API бэкенда
    handle /api/* {
        reverse_proxy backend:8000 {
            header_up X-Real-IP {remote_host}
            header_up X-Forwarded-For {remote_host}
            transport http {
                dial_timeout 5s
                response_header_timeout 120s
                read_timeout 130s
            }
        }
    }

    # WebSocket
    handle /ws/* {
        reverse_proxy backend:8000
    }

    # Storage (изображения)
    handle /storage/* {
        root * /var/www
        file_server
    }

    # Frontend SPA (catch-all — должен быть последним)
    handle {
        root * /var/www/frontend
        try_files {path} /index.html
        file_server
    }

    # Upload limit для EPUB
    @uploads {
        path /api/v1/books/upload /api/v1/books/*/upload
    }
    request_body @uploads {
        max_size 50MB
    }

    # Security headers
    header {
        X-Frame-Options SAMEORIGIN
        X-Content-Type-Options nosniff
        Referrer-Policy strict-origin-when-cross-origin
        -Server
    }
}

# www -> non-www редирект
www.fancai.ru {
    redir https://fancai.ru{uri} permanent
}
```

2. Модифицировать `frontend/Dockerfile.prod` для shared volume вместо встроенного nginx:
   - Текущий Dockerfile: Stage 1 (builder) -> Stage 2 (nginx + COPY --from=builder)
   - Новый Dockerfile: Stage 1 (builder) -> Stage 2 (minimal alpine, копирует dist в /var/www/html)
   - Frontend контейнер больше НЕ запускает nginx — он только собирает и кладёт артефакты в volume
   - Конкретная реализация:
     ```dockerfile
     # Stage 1: Build (без изменений)
     FROM node:22-alpine AS builder
     WORKDIR /app
     COPY package*.json ./
     RUN npm ci --legacy-peer-deps --silent
     COPY . .
     ARG VITE_API_BASE_URL=/api/v1
     # ... остальные ARG ...
     RUN npm run build

     # Stage 2: Output (заменяет nginx stage)
     FROM alpine:3.21
     # Копируем build артефакты в путь для shared volume
     COPY --from=builder /app/dist /var/www/html
     # Контейнер завершается сразу — артефакты доступны через volume
     CMD ["echo", "Frontend build complete"]
     ```
   - Сохранить проверку Service Worker: `RUN test -f dist/sw.js` в builder stage
   - Сохранить все ARG для VITE_* переменных в builder stage

3. Обновить `docker-compose.lite.prod.yml`:
   - Заменить nginx-сервис на caddy-сервис:
     ```yaml
     caddy:
       image: caddy:2-alpine
       container_name: fancai_caddy
       ports:
         - "80:80"
         - "443:443"
         - "443:443/udp"   # HTTP/3 (QUIC) — ОБЯЗАТЕЛЬНО UDP
       volumes:
         - ./Caddyfile:/etc/caddy/Caddyfile:ro
         - caddy_data:/data
         - caddy_config:/config
         - ./backend/storage:/var/www/storage:ro
         - frontend_build:/var/www/frontend:ro
       depends_on:
         frontend:
           condition: service_completed_successfully
         backend:
           condition: service_healthy
       networks:
         - bookreader_network
       restart: unless-stopped
       deploy:
         resources:
           limits:
             cpus: '0.5'
             memory: 128M
     ```
   - Обновить frontend-сервис для shared volume:
     ```yaml
     frontend:
       image: bookreader-frontend:lite
       build:
         context: ./frontend
         dockerfile: Dockerfile.prod
         args:
           - VITE_API_URL=${DOMAIN_URL:-http://localhost}/api/v1
           - VITE_WS_URL=${DOMAIN_URL:-http://localhost}/ws
           - VITE_APP_NAME=BookReader AI
       container_name: bookreader_frontend
       volumes:
         - frontend_build:/var/www/html    # shared volume: frontend пишет, caddy читает
       restart: "no"                        # контейнер завершается после build
       networks:
         - bookreader_network
     ```
   - Добавить volumes в секцию volumes:
     ```yaml
     volumes:
       caddy_data:       # SSL сертификаты (Caddy управляет)
       caddy_config:     # Caddy конфигурационный кеш
       frontend_build:   # Build артефакты фронтенда (shared: frontend -> caddy)
     ```
   - ВАЖНО: Caddy монтирует `frontend_build:/var/www/frontend:ro`, а frontend пишет в `frontend_build:/var/www/html`. Пути внутри volume должны совпадать — либо frontend пишет в root volume, либо Caddy читает из подпапки. Рекомендация: frontend копирует в `/var/www/html` (root of volume), Caddy монтирует volume в `/var/www/frontend` — файлы будут доступны по `/var/www/frontend/*`.
   - Удалить все ссылки на nginx в комментариях
