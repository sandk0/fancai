<objective>
Устранение корневых причин нестабильности highlighting в epub.js: ResizeObserver cascade при DOM span wrapping, конфликты между тремя highlighting-системами, CSS padding conflict, недостаточное подавление Chrome Touch to Search.

Purpose: Фазы 19.1 и 19.2 исправляли симптомы, но на реальном устройстве (Pixel 9) фиксы не работают из-за корневой причины — ResizeObserver в epub.js contents.js детектирует изменение размеров после span wrapping и запускает cascade (RESIZE -> expand -> layout.format -> clear -> display), уничтожая все кастомные spans. Дополнительно: три highlighting-системы конфликтуют через normalize() и неполные skip-фильтры.

Output: Утилита resizeSuppression.ts, исправленные highlighting hooks (skip-фильтры, без normalize(), с resize suppression), исправленный CSS padding, усиленное подавление Touch to Search. Полный набор unit-тестов.
</objective>

contents.js:
```javascript
// line 526-534: ResizeObserver creation
this.observer = new ResizeObserver(() => {
  requestAnimationFrame(this.resizeCheck.bind(this));
});
this.observer.observe(this.document.documentElement);

// line 429-443: resizeCheck()
resizeCheck() {
  let width = this.textWidth();
  let height = this.textHeight();
  if (width != this._size.width || height != this._size.height) {
    this._size = { width, height };
    this.onResize && this.onResize(this._size);
    this.emit(EVENTS.CONTENTS.RESIZE, this._size);
  }
}
```

Rendition API:
```typescript

// contents[0] internal: { observer: ResizeObserver, _size: {width, height}, document: Document, textWidth(): number, textHeight(): number }
```
