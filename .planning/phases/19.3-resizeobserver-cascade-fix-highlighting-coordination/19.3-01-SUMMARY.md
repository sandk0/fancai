## Accomplishments
- Создана утилита resizeSuppression.ts с 3 экспортами: withResizeSuppression (sync), disconnectResizeObserver и reconnectResizeObserver (async)
- Все 3 highlighting-системы обёрнуты в resize suppression: аннотации и entity — sync wrapper, descriptions — async disconnect/reconnect
- TreeWalker skip-фильтры расширены: useDescriptionHighlighting теперь пропускает .entity-mention и .user-annotation, useEntityNameHighlighting — .user-annotation
- normalize() удалён из всех cleanup-ов (useAnnotationRendering, useDescriptionHighlighting, useEntityNameHighlighting)
- CSS padding: 0.75em !important удалён из useContentHooks body — epub.js layout.format() единственный источник padding
- Touch to Search: selection-blocked class добавляется при touchstart, убирается при touchend

## Decisions Made
- disconnect/reconnect ResizeObserver вместо _size freeze — observer callback вообще не запускается при disconnect, что безопаснее
- Async disconnect/reconnect для useDescriptionHighlighting — processContents использует requestIdleCallback chunks, withResizeSuppression не подходит (синхронная)
- CSS padding удалён полностью из useContentHooks — epub.js layout.format() управляет padding через columns(), !important override конфликтовал
- selection-blocked class на touchstart + remove на touchend вместо только selectstart listener — двухуровневая защита от Chrome Touch to Search
