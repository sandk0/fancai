Создать `backend/Dockerfile.celery` — multi-stage build по шаблону Dockerfile.prod, но с NLP-зависимостями. Структура (per D-04, D-05):

**Builder stage (python:3.12-slim as builder):**
- ENV: PYTHONUNBUFFERED=1, PYTHONDONTWRITEBYTECODE=1, PIP_NO_CACHE_DIR=1, PIP_DISABLE_PIP_VERSION_CHECK=1
- apt-get: gcc g++ libpq-dev build-essential
- WORKDIR /tmp
- Слой 1 (тяжёлый, кэшируется отдельно): `pip install --no-cache-dir torch==2.11.0+cpu --index-url https://download.pytorch.org/whl/cpu`
- Слой 2 (NLP, меняется редко): `pip install --no-cache-dir gliner2==1.2.4 sentence-transformers==5.3.0 scikit-learn==1.8.0 pgvector==0.4.2`
- Слой 3 (requirements.txt): COPY requirements.txt . && pip install --no-cache-dir -r requirements.txt

**Production stage (python:3.12-slim as production):**
- ENV: PYTHONUNBUFFERED=1, PYTHONDONTWRITEBYTECODE=1, PYTHONPATH=/app, HF_HOME=/models (per D-07)
- apt-get: libpq5 curl
- groupadd/useradd appuser (идентично Dockerfile.prod)
- COPY --from=builder site-packages и bin
- WORKDIR /app, COPY --chown=appuser:appuser . .
- mkdir -p /app/logs /app/storage /models && chown -R appuser:appuser /app /models && chmod +x /app/entrypoint.prod.sh
- USER appuser
- HEALTHCHECK --interval=60s --timeout=15s --start-period=120s --retries=3 CMD celery -A app.core.celery_app inspect ping --timeout 10 || exit 1
- ENTRYPOINT ["/app/entrypoint.prod.sh"]
- CMD ["celery", "-A", "app.core.celery_app", "worker", "--loglevel=info", "--concurrency=1", "--max-tasks-per-child=0", "--prefetch-multiplier=1"]

Важно:
- start_period=120s (не 30s как в Dockerfile.prod) — NLP модели грузятся медленнее (per D-08)
- --max-tasks-per-child=0 (не 100) — модели persist в памяти, worker не перезапускается (per D-08)
- --concurrency=1 — один NLP процесс (per D-08)
- НЕ включать --max-memory-per-child (было 512000 — убивает NLP worker, ловушка 2 из RESEARCH.md)
