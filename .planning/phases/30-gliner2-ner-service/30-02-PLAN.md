    **1. Создать `backend/scripts/export_ner_ab_data.py`** — скрипт для экспорта данных из production DB:

    ```python
    """
    Экспорт данных для A/B тестирования NER.

    Использование:
        uv run python scripts/export_ner_ab_data.py --book-id <UUID> --output tests/fixtures/ner_ab_data/
        uv run python scripts/export_ner_ab_data.py --auto-select 5 --output tests/fixtures/ner_ab_data/
    """
    ```

    Скрипт должен:
    - Подключаться к production DB через DATABASE_URL из environment/.env
    - Для каждой книги экспортировать два файла:
      - `{book_slug}_chapters.json`: `{"book_title": str, "book_id": str, "chapters": [{"chapter_number": int, "content": str}]}`
      - `{book_slug}_baseline.json`: `{"book_title": str, "book_id": str, "entities": [{"name": str, "type": str, "chapter_numbers": [int]}]}`
    - `--auto-select N`: выбрать N книг с наибольшим количеством entities (минимум 10 entities на книгу)
    - Использовать asyncio + SQLAlchemy async для DB access
    - Импорты: `from app.models.entity import Entity`, `from app.models.chapter import Chapter`, `from app.models.book import Book`
    - Транслитерация/slugify title для filename: `re.sub(r'[^\w]', '_', book.title.lower())[:30]`
    - argparse для CLI: `--book-id` (UUID), `--auto-select` (int), `--output` (path, default=tests/fixtures/ner_ab_data/), `--min-entities` (int, default=10)
    - Entity baseline: SELECT entities WHERE book_id = X, JOIN entity_mentions для chapter_numbers
    - Chapter content: SELECT chapters WHERE book_id = X, ORDER BY chapter_number
