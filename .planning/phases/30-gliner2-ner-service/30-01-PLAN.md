<objective>
NERService — полный цикл от извлечения entities через GLiNER2 до интеграции в pipeline обработки книг.

Назначение: Заменить LLM для NER-задачи (entity extraction) на локальную GLiNER2 модель. Сервис разбивает текст главы на чанки, извлекает entities, дедуплицирует overlap, конвертирует в формат ConsistencyManager и интегрируется через feature flag.

Результат: ner_service.py (NERService + TextChunker + NERAdapter), NER метрики в metrics.py, интеграция в book_tasks.py, unit-тесты.
</objective>

    - `chunk_text(text, tokenizer, max_tokens=384, overlap_sentences=2) -> list[TextChunk]`
    - Sentence splitting через `razdel.sentenize()` — возвращает `Substring(start, stop, text)`
    - Token counting через `tokenizer.encode(sent.text, add_special_tokens=False)`
    - Если весь текст < max_tokens — один чанк (D-09)
    - Overlap: следующий чанк начинается на `max(j - overlap_sentences, i + 1)` предложений назад
    - `start_offset = chunk_sents[0].start`, `end_offset = chunk_sents[-1].stop` из razdel Substring

    **2. NERAdapter** (per D-10, D-11, D-12, D-13, D-14):
    ```python

    }
    ```
    - `deduplicate_overlap_entities(all_entities: list[dict]) -> list[dict]` — по ключу `(start, end, name.casefold())`, оставляем с большим confidence
    - `adapt_to_chapter_result(raw_entities: list[dict], chunk_offsets: list[tuple[int, int]]) -> ChapterAnalysisResult` — пересчёт offsets (entity.start + chunk.start_offset), агрегация mentions по casefold имени, фильтр len(name) < 2, создание ExtractedEntity с defaults из D-11, return ChapterAnalysisResult(entities=..., descriptions=[], relationships=[])

    **3. NERService** (per D-01, D-03, D-04, D-05):

    - `_ensure_loaded()` загружает:
