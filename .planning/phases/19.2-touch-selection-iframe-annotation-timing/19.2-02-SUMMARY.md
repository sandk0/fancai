## Accomplishments

## Decisions Made
- hooks.content.register для аннотаций вместо rendered event — epub.js lifecycle гарантирует: hooks.render -> hooks.content -> emit('rendered'). Регистрация через hooks.content обеспечивает применение аннотаций ДО финального рендеринга
- annotationHook в отдельном hooks.content useEffect (deps: rendition, enabled, currentChapter) + отдельный bookmark-change useEffect (deps: bookmarks) — разделение ответственности
- renderedDebounceRef полностью удален — rendered event больше не используется для аннотаций
