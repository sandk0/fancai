### Требуется ручная верификация

#### 1. Chrome Touch to Search — подавление (BUG-1)

**Тест:** Открыть книгу на Pixel 9 (Android Chrome), сделать короткий тап (<300ms) по тексту
**Ожидание:** Chrome Touch to Search popup НЕ должен появляться; тап должен обрабатываться как навигация или toggle UI
**Почему ручное:** Chrome Touch to Search API не воспроизводится в JSDOM — требует реального Android Chrome

#### 2. Long-press для выделения (BUG-1)

**Тест:** На том же устройстве, удерживать палец на тексте более 300ms
**Ожидание:** После 300ms появляется курсор выделения текста; можно выделить фрагмент для создания заметки
**Почему ручное:** Long-press timing и cursor selection behavior специфичны для Android Chrome

#### 3. Edge tap на интерактивный элемент (BUG-5)

**Тест:** Тапнуть на entity-mention или description-highlight расположенный у края экрана (в 15% зоне)
**Ожидание:** Открывается popup с информацией об entity/description, а НЕ срабатывает навигация prev/next
**Почему ручное:** iframe-viewport coordinate system не имитируется в JSDOM

#### 4. Немедленное отображение аннотаций (BUG-4)

**Тест:** Создать новую заметку/выделение; переключиться на другую страницу и обратно
**Ожидание:** Аннотация отображается мгновенно при загрузке страницы, без мерцания (нет момента без аннотации)
**Почему ручное:** epub.js hooks.content lifecycle не воспроизводим в JSDOM

### Итог

Все автоматически верифицируемые аспекты цели фазы реализованы корректно:

- **BUG-1**: Архитектурное решение правильное — selectstart listener с timing-based подавлением (300ms порог) регистрируется через hooks.content в iframe document. Это единственный способ заблокировать Chrome Touch to Search (CSS touch-action не работает на уровне Touch to Search API).

- **BUG-5**: Двойное вычитание устранено — `elementFromPoint` в `handleTouchEnd` и `handleClick` получает `touch.clientX / e.clientX` напрямую. iOS overlay корректно сохраняет конвертацию `screen → iframe` через `iframe.getBoundingClientRect()` (это events из parent document, не из iframe). `getIframeRect` helper удалён полностью.

- **BUG-4**: Annotation rendering мигрирован с `rendition.on('rendered')` на `rendition.hooks.content.register(annotationHook)`. `renderedDebounceRef` удалён. `bookmarkDebounceRef` (50ms) сохранён для немедленного обновления при создании/редактировании заметок. Архитектурно это гарантирует применение аннотаций ДО emit('rendered').

Все 4 успешных критерия ROADMAP.md реализованы на уровне кода. Финальное подтверждение требует UAT на реальном Android устройстве.
