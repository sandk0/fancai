       - Когда iOS overlay вызывает onCenterTap, entity тапы в center zone не обрабатываются
       - FIX: добавить проверку `.entity-mention` в handleCenterTap:
         ```typescript
         // После while loop для description-highlight, добавить аналогичный для entity-mention:

         // Если найден: получить data-entity-id, найти entity в entityList, вызвать handleEntityClick
         ```

    2. **iOS overlay handler (useGestureController.ts строки 909-953):**
       - handleOverlayTouchEnd вызывает onCenterTapRef.current(viewportX, viewportY)
       - Этот onCenterTap = handleCenterTap в EpubReader -- после фикса #1 entity detection будет работать
       - НО: overlay также вызывает onToggleUIRef.current() ПОСЛЕ onCenterTap
       - Если описание/сущность найдены, UI toggle не должен происходить
       - FIX: handleCenterTap должен ВОЗВРАЩАТЬ boolean (true = interactive element found)
         * Изменить тип onCenterTap: `(x: number, y: number) => Promise<boolean> | boolean`
         * В handleCenterTap: return true если найден description или entity, false иначе
         * В iOS overlay: `const handled = await onCenterTapRef.current(viewportX, viewportY); if (!handled) onToggleUIRef.current();`
         * В iframe touchend center tap (строка 542-548): аналогично -- toggle UI только если !handled
         * В desktop click handler (строка 755-757): аналогично

    3. **Edge zone на iframe (getInteractiveType уже работает):**
       - Проверить что getInteractiveType вызывается ПЕРЕД getTapAction
       - В текущем коде (строка 528-534): `const interactiveType = getInteractiveType(e.target); if (interactiveType) { ... return; }`
       - Для entity: interactiveType === 'entity' -> return (тап не перехватывается навигацией) -> epub.js click handler сработает

       - НО: для desktop click (строка 743-748): тоже `getInteractiveType` -> return -> клик обрабатывается epub.js
