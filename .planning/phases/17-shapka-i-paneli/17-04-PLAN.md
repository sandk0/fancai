  <action>
В useGestureController.ts, в useEffect для iOS center-tap overlay (строки ~855-938):

1. Изменить top overlay чтобы он начинался НИЖЕ шапки:
   ```typescript
   overlay.style.cssText = `
     position: absolute;
     top: calc(env(safe-area-inset-top) + 64px);   // 64px = высота шапки (~56px header + 8px padding)
     bottom: env(safe-area-inset-bottom);
     left: 15%;
     right: 15%;
     z-index: 5;
     background-color: transparent;
     touch-action: pan-x pan-y;
     -webkit-tap-highlight-color: transparent;
     -webkit-user-select: none;
     user-select: none;
   `;
   ```

2. ДОПОЛНИТЕЛЬНАЯ ЗАЩИТА: В handleOverlayTouchEnd, перед вызовом onToggleUIRef.current(), добавить проверку Y-координаты:
   ```typescript
   // Не вызывать toggleUI если тап в области header (< 80px от верха viewport)
   const headerThreshold = 80; // safe-area + header height
   if (touch.clientY < headerThreshold) {
     return;
   }
   ```
   Эту проверку добавить после проверки `if (duration >= TAP_MAX_DURATION || ...)` и перед вызовом onCenterTapRef.current().

Обе защиты работают совместно: top offset предотвращает overlay от покрытия header area, а проверка clientY — fallback на случай если что-то пошло не так с CSS.

Добавить комментарий на русском: "// FIX: overlay не должен покрывать область шапки (см. debug/header-click-hides-immediately.md)"
