  <action>
Полностью переписать ReaderHeader.tsx с адаптивным layout и overflow menu.

**Структура layout шапки:**
```
[Назад] [Оглавление?] ... [Прогресс по центру] ... [Сущности?] [Поиск?] [Настройки?] [Overflow?]
```
Где `?` = условно видимы через Tailwind responsive classes.

**Breakpoints появления кнопок (решение пользователя):**
- < 375px (320px): Назад (иконка без текста) + процент по центру + overflow (MoreVertical) -- 3 элемента
- xs (375px)+: + Оглавление выходит из overflow
- sm (640px)+: + Сущности, Поиск выходят из overflow. Прогресс показывает полосу + страница/всего
- md (768px)+: + Настройки выходит из overflow. Overflow скрыт. Название книги и автор по центру

**Адаптивный прогресс (решение пользователя):**
- 320px: только «42%» по центру (font-bold text-sm tabular-nums), без полосы, без страницы/всего
- xs (375px)+: процент + полоса прогресса (role="progressbar", h-1.5 rounded-full)
- sm (640px)+: процент + полоса + страница/всего (font-medium text-xs text-muted-foreground)
- На 320px прогресс flex-1 flex-col items-center (по центру шапки, как Apple Books)

**Overflow menu:**
- Использовать Radix DropdownMenu из `@/components/UI/dropdown-menu`
- Иконка: MoreVertical из lucide-react (решение пользователя)
- Trigger: `className="md:hidden"` -- скрыт от md+
- Content: align="end"
- Формат пунктов: `<DropdownMenuItem onClick={handler}>` с иконкой слева + название справа (решение пользователя)
- Порядок пунктов (Claude's discretion): Оглавление, Сущности, Поиск, Настройки
- Обратные responsive classes на пунктах: `className="xs:hidden"` для Оглавления (скрывать в overflow когда кнопка уже видна), `className="sm:hidden"` для Сущностей и Поиска, `className="md:hidden"` для Настроек
- Анимация: стандарт Radix (fade+scale), без badge на кнопке (решение пользователя)

**Удалить из props:** `onInfoOpen` -- кнопка Инфо переносится в TocSidebar.
**Оставить все props:** isVisible, title, author, progress, currentPage, totalPages, onBack, onTocToggle, onSettingsOpen, onEntitiesOpen, onSearchToggle.

**Сохранить:** memo wrapper, AnimatePresence + m.div с HEADER_SPRING для show/hide, fixed positioning, z-10, backdrop-blur-md, mt-safe, touch-target (min-h-[44px] min-w-[44px]) на всех кнопках, aria-label на всех кнопках, role="progressbar" на полосе.

**Важно:** Padding шапки адаптивный: `px-2 xs:px-4 py-3 gap-2`. На 320px минимальные отступы.
