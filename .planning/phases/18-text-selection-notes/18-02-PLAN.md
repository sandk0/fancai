Создать новый компонент `HighlightTooltip.tsx` в `frontend/src/components/Reader/`.

**Props interface:**
```typescript
import type { HighlightPopup } from '@/hooks/epub/useAnnotationRendering';

interface HighlightTooltipProps {
  popup: HighlightPopup | null;
  onEdit: (bookmarkId: string) => void;
  onDelete: (bookmarkId: string) => void;
  onClose: () => void;
}
```

ВАЖНО: тип `HighlightPopup` нужно экспортировать из useAnnotationRendering.ts (сейчас он не экспортирован). Добавить `export` к интерфейсу `HighlightPopup` в useAnnotationRendering.ts.

**Компонент:**
- Если `popup === null`, рендерить `null`
- Компактная карточка с fixed позиционированием, аналогично SelectionMenu.tsx (getMenuStyle pattern)
- Стилистика: `bg-popover text-popover-foreground rounded-lg shadow-lg border` (Tailwind, как SelectionMenu)
- Позиционирование: использовать `popup.position.x` и `popup.position.y`
  - Если position.y > 50% viewport — показать сверху точки тапа
  - Если position.y <= 50% viewport — показать снизу точки тапа
  - Горизонтально по центру (popup.position.x), с clamp чтобы не выходить за экран
- Padding: `p-3`
- Max-width: `max-w-[280px]`

**Содержимое tooltip:**
1. **Текст заметки** (если `popup.note` не null и не пустая строка):
   - `<p>` с `text-sm text-muted-foreground line-clamp-3` (максимум 3 строки)
   - Если note пустая/null — не показывать этот блок, только кнопки
2. **Цветовой индикатор**: маленький кружок (8px) с цветом `popup.color` (если есть)
3. **Кнопки** в горизонтальном flex:
   - **Edit** (Pencil icon из lucide-react): `onClick={() => onEdit(popup.bookmarkId)}`
   - **Delete** (Trash2 icon из lucide-react): `onClick={() => onDelete(popup.bookmarkId)}`, `text-destructive` цвет
   - Кнопки с `min-h-[44px] min-w-[44px]` touch target
   - Иконки размером 18px

**Click outside для закрытия:**
- useEffect с document.addEventListener('pointerdown') — если клик вне tooltip, вызвать onClose
- useRef на tooltip контейнер для проверки contains()
- Cleanup в return useEffect

**Анимация:**
- Без анимации — простой conditional render (per user decision: без toast, без haptic)

Использовать `memo` из React для оптимизации.

Не забыть добавить `export` к `HighlightPopup` interface в `useAnnotationRendering.ts`.
