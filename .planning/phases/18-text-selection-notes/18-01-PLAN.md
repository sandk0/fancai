Разместить этот блок на месте удалённого `@media (pointer: coarse)` блока.

```typescript
// На десктопе оставляем оба меню (нативное right-click + SelectionMenu)
const handleContextMenu = (e: Event) => {
```

```typescript
// Selection passthrough: если пользователь drag-ит selection (расширяет выделение),
// отменить gesture чтобы не перехватывать drag handles
const sel = doc.defaultView?.getSelection?.();
if (sel && sel.toString().length > 0) {
  touchRef.current = { ...INITIAL_TOUCH, state: 'cancelled' };
  return;
}
```
Переменная `doc` уже доступна в замыкании contentHook. Используй `INITIAL_TOUCH` для сброса состояния (уже определён в файле).

2. **Добавить toggle CSS class `selection-blocked`** -- добавить useEffect в тело хука useGestureController (после определения `phase` state, перед return), который управляет CSS class на body iframe документа:
```typescript
// Toggle selection-blocked class based on animation phase
// Prevents text selection during spring animations (DOM is moving)
useEffect(() => {
  if (!rendition) return;
  const contents = rendition.getContents();
  contents.forEach((c: unknown) => {
    const doc = (c as { document: Document }).document;
    if (!doc?.body) return;
    if (phase !== 'idle') {
      doc.body.classList.add('selection-blocked');
    } else {
      doc.body.classList.remove('selection-blocked');
    }
  });
}, [rendition, phase]);
```
Разместить этот useEffect ПОСЛЕ всех существующих useEffect, перед `return { translateX, phase, ... }`.
