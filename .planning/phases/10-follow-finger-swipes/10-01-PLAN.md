**Spring конфигурации (critically damped = damping ~= 2*sqrt(stiffness*mass)):**
- SPRING_FAST: stiffness=400, damping=40, mass=1 (для flick, ~150ms)
- SPRING_NORMAL: stiffness=300, damping=35, mass=1 (для обычного свайпа, ~250ms)
- SPRING_RUBBER: stiffness=200, damping=28, mass=1 (для rubber-band возврата)
- Выбор: velocity > 0.5 -> FAST, velocity > 0.1 -> NORMAL, else RUBBER

**Интерфейс хука:**
```typescript
interface UseFollowFingerSwipeOptions {
  rendition: Rendition | null;
  enabled: boolean;
  onNavigate: (direction: 'next' | 'prev') => Promise<void>;
  onChapterChange?: (direction: 'next' | 'prev') => Promise<void>;
  navLock: NavigationLock;
}

interface UseFollowFingerSwipeReturn {
  translateX: MotionValue<number>;
  phase: 'idle' | 'tracking' | 'animating';
  isAtBoundary: 'start' | 'end' | null;
  showChapterHint: boolean;
  chapterHintDirection: 'next' | 'prev' | null;
}
```

**Реализация:**
1. `useMotionValue(0)` для translateX — ref-based, без ререндеров
2. `useRef` для phase, animationControls, touch state (startX, startY, startTime, lastTouchX, lastTouchTime, isSwiping)
3. `useState` минимальный: только для phase (нужен для компонентов) и boundary state
4. Touch events через `rendition.hooks.content.register()` — паттерн из useSwipeNavigation:
   - touchstart: запомнить позицию, проверить boundary, НЕ начинать tracking (ждём touchmove)
   - touchmove: если deltaX > tapVsSwipeThreshold — начать follow-finger. Обновлять translateX.set(deltaX). При boundary — rubber-band (deltaX * resistance, clamped to maxRubberBand). При vertical scroll (deltaY/deltaX > maxVerticalRatio) — отменить. e.preventDefault() если горизонтальный (passive: false на touchmove)
   - touchend: рассчитать velocity. Определить shouldNavigate (по offset или velocity). Запустить animate(translateX, target, spring). В onComplete: translateX.set(0), вызвать onNavigate или onChapterChange
5. getStageInfo() — exported utility: получить stage.container, scrollLeft, scrollWidth, clientWidth, isAtStart, isAtEnd, viewportWidth
6. shouldNavigate() — exported utility: проверка offset/velocity по FOLLOW_FINGER_CONFIG
7. calculateVelocity() — exported utility: (currentX - lastX) / (currentTime - lastTime)
8. getRubberBandOffset() — exported utility: deltaX * resistance, clamped to maxRubberBand
9. При новом touchstart во время spring-анимации — stop() текущей анимации, начать новый tracking с текущей позиции translateX.get()
10. Взаимодействие с navLock: acquire при touchend (начало навигации), release после onComplete. НЕ acquire при touchstart — follow-finger визуальный, lock только для навигации
11. При активном long-press/selection (проверка через window.getSelection().toString().length > 0) — не начинать follow-finger

**Anti-patterns (из RESEARCH.md, НЕ делать):**
- НЕ использовать useState для offset (вызывает ререндеры на каждый touchmove)
- НЕ вызывать onNavigate до завершения spring-анимации
- НЕ применять transform напрямую к stage.container (epub.js может перезаписать)
- touchmove listener ОБЯЗАТЕЛЬНО passive: false (для preventDefault)

**Props:**
```typescript
interface FollowFingerContainerProps {
  translateX: MotionValue<number>;
  phase: 'idle' | 'tracking' | 'animating';
  isAtBoundary: 'start' | 'end' | null;
  showChapterHint: boolean;
  chapterHintDirection: 'next' | 'prev' | null;
  children: React.ReactNode;
}
```

**Реализация:**
1. Внешний div с `overflow: hidden` и `width: 100%`, `height: 100%`, `position: relative`
2. `m.div` (из motion/react) с `style={{ x: translateX }}` — GPU-accelerated transform
3. Внутри m.div — {children} (epub-viewer передается как children)
4. Box-shadow между страницами: `useMotionValueEvent(translateX, 'change', (v) => ...)` для реактивного обновления тени. Тень — отдельный абсолютно позиционированный div на краю видимой области:
   - При offset < 0 (свайп влево, next): тень на правом краю текущей страницы
   - При offset > 0 (свайп вправо, prev): тень на левом краю текущей страницы
   - Opacity и blur пропорциональны progress (|offset| / (viewport * 0.25)), max opacity 0.15, max blur 20px
   - Формат: `box-shadow: Npx 0 Npx -N/2px rgba(0,0,0,opacity)` на отдельном div-разделителе шириной 1px
5. `pointer-events: none` на wrapper когда phase !== 'idle' — чтобы transform не ломал hit testing (из Pitfall 6 в RESEARCH.md)
6. ChapterHint рендерится внутри FollowFingerContainer когда showChapterHint=true

**Решение по CSS-методу (Claude's Discretion из CONTEXT.md):**
- Использовать CSS transform через m.div (не scrollLeft) — GPU compositor, 60fps
- Transform на wrapper div (не на stage.container) — безопасно для epub.js (Pitfall 1)
- overflow: hidden на wrapper clip-ает видимую область, соседние CSS-колонки видны при сдвиге (Подход B из RESEARCH.md)
