  <files>frontend/src/hooks/epub/useDescriptionHighlighting.ts</files>
  <action>
    1. **Добавить highlightMode в options**:
       - В `UseDescriptionHighlightingOptions` добавить: `highlightMode?: DescriptionHighlightMode;` (импорт из `@/stores/reader`)
       - Default: `'anchor'`

    2. **Исправить preprocessDescription** (строка 39):
       - Поменять приоритет: `const content = desc.content || desc.text || '';` (content primary, text fallback)
       - Это критично: desc.text может быть truncated preview из image-related schemas

    3. **Добавить CSS-стили для full-режима**:
       - В секции стилей (строка ~117-124) добавить стили для `.description-highlight-full`:
         - Лёгкий полупрозрачный фон: `background: rgba(var(--type-color-rgb), 0.08);` — реализовать через отдельные CSS-классы
         - Без border-bottom (в отличие от anchor)
         - cursor: pointer
       - Anchor стили (существующие `.desc-*`) остаются без изменений — насыщенный стиль с border-bottom
       - Для full-mode создать аналогичные классы `.desc-full-location`, `.desc-full-character`, и т.д. с уменьшенной прозрачностью:
         - location: `rgba(96,165,250,0.08)`, character: `rgba(167,139,250,0.08)`, etc.
         - Hover: увеличить до `0.15`
         - Без border-bottom

    4. **Реализовать full-mode wrapping** — новая функция `wrapFullDescription`:
       - Принимает: `doc: Document, anchorNode: Text, anchorStartIdx: number, descContent: string, descData: Description, hasImage: boolean`
       - Алгоритм:
         a. Нормализовать `descContent` тем же `normalizeText()`
         b. Начиная с `anchorNode`, собрать текст из последовательных text nodes через TreeWalker
         c. Конкатенировать нормализованный текст nodes, искать в нём нормализованный descContent
         d. Когда найден — определить начальный и конечный text nodes и offsets
         e. Обернуть каждый text node (или его часть) в span с классом `description-highlight description-highlight-full desc-full-{type}`
         f. Для split используем pattern из useAnnotationRendering: `node.splitText(offset)` для первого/последнего nodes
       - Если descContent не найден в собранном тексте — fallback на anchor-mode для этого описания
       - Проверять `isInsideProtectedHighlight` аналогично useAnnotationRendering: пропускать nodes внутри `.user-annotation`

    5. **Модифицировать processContents** (строка ~83):
       - Добавить `highlightMode` в зависимости useCallback
       - В цикле по nodes (строка ~139-166):
         - Если `highlightMode === 'anchor'` (или default): текущая логика без изменений
         - Если `highlightMode === 'full'`:
           a. Найти anchor позицию через существующие стратегии (как сейчас)
           b. Вызвать `wrapFullDescription()` для full-mode wrapping
           c. Если wrapFullDescription не нашел полный текст — fallback на anchor wrapping
       - При cleanup (строка ~107-111): удалять и `.description-highlight-full` spans

    6. **Добавить highlightMode в deps processContents и useEffect**:
       - processContents useCallback deps: добавить highlightMode
       - При смене highlightMode нужен force re-process: добавить highlightMode в `currentIds` строку (строка ~88) чтобы пересчитывать при смене режима
