    1. **normalizeText()** — расширить:

       - Добавить `\u200B` (zero-width space) → удаление: `.replace(/\u200B/g, '')`
       - Добавить `\u2011` (non-breaking hyphen) → '-': `.replace(/\u2011/g, '-')`

    2. **buildIndexMap()** — ПЕРЕПИСАТЬ для поддержки всех трансформаций normalizeText:

       - Алгоритм: идти по оригинальному тексту, для каждого символа определять что делает normalizeText:
         - `\u00AD`, `\u200B` → пропустить (не добавлять в map)
         - `\u00A0` → как пробел (whitespace collapse logic)
         - `\u2026` → добавить 3 записи в map, все указывающие на позицию `…` в оригинале
         - `«»""` → 1:1 (обычный символ)
         - `\u2013\u2014` → 1:1 (обычный символ)
         - `\u2011` → 1:1 (обычный символ)
         - пробельные → whitespace collapse (текущая логика)
         - остальные → 1:1
       - Trim logic (skip leading whitespace, remove trailing) — сохранить как есть
       - **Критически важно**: indexMap.length ДОЛЖЕН равняться normalizeText(original).length после рефактора
