## Phase Details

### Phase 9: Стабилизация навигации
**Goal**: Пользователь может стабильно перелистывать страницы без блокировок, сбоев или пропуска страниц при любой скорости взаимодействия
**Depends on**: Nothing (первая фаза milestone v1.1)
**Requirements**: NAV-03, NAV-04, NAV-06
**Success Criteria** (what must be TRUE):
  1. Быстрые свайпы подряд (3-5 за секунду) корректно перелистывают страницы без смещения или зависания
  2. После отмены генерации изображения (или закрытия любого модала) навигация работает немедленно — нет блокировки
  3. Быстрые тапы в зоне навигации не вызывают пропуск страниц или двойную навигацию
  4. При любом сценарии прерывания (закрытие модала, переход в фон, быстрые жесты) навигация автоматически восстанавливается в течение 3 секунд
**Plans:** 2/2 plans complete

Plans:
- [x] 09-01-PLAN.md — Единый навигационный lock + serialized directScroll + тесты
- [x] 09-02-PLAN.md — Интеграция lock в gesture handlers + удаление debug overlay

### Phase 10: Follow-finger свайпы
**Goal**: Палец пользователя физически двигает страницу в реальном времени, как в Apple Books / Google Play Books, с плавной spring-анимацией завершения
**Depends on**: Phase 9
**Requirements**: NAV-01, NAV-02
**Success Criteria** (what must be TRUE):
  1. При горизонтальном свайпе страница следует за пальцем в реальном времени — видна следующая/предыдущая страница за краем текущей
  2. При отпускании пальца страница плавно анимируется к финальной позиции с spring physics (не телепортируется)
  3. Скорость жеста влияет на результат: медленный свайп возвращает страницу назад, быстрый — перелистывает даже при малом смещении
  4. На границе главы (последняя/первая страница) отображается корректный rubber-band эффект вместо пустоты
**Plans:** 2/2 plans complete

Plans:
- [x] 10-01-PLAN.md — Хук useFollowFingerSwipe + компоненты FollowFingerContainer и ChapterHint
- [x] 10-02-PLAN.md — Интеграция в EpubReader + slide-in тап-анимация + удаление SwipeOverlay

### Phase 11: Единый gesture handler и мобильный UI
**Goal**: Все touch-взаимодействия управляются единой системой без конфликтов, а мобильный интерфейс адаптирован для комфортного чтения одной рукой
**Depends on**: Phase 10
**Requirements**: NAV-05, MUI-01, MUI-02, MUI-03, MUI-04, MUI-05, MUI-06
**Success Criteria** (what must be TRUE):
  1. Свайп, тап и long-press не конфликтуют — каждый жест распознается корректно без двойной навигации или ложных срабатываний
  2. Все кнопки и интерактивные элементы ридера имеют минимум 44px touch target и легко нажимаются большим пальцем
  3. Header и footer автоматически скрываются при чтении и появляются по тапу в центральной зоне экрана
  4. Entity drawer, настройки и оглавление открываются/закрываются с плавной spring-анимацией и адаптированы для мобильных экранов (полная ширина, правильные отступы)
  5. Переход библиотека-ридер сопровождается плавной motion-анимацией
**Plans:** 3/3 plans complete

### Phase 12: Viewport и iOS
**Goal**: Ридер корректно отображается на всех мобильных устройствах с учетом safe areas, клавиатуры и особенностей PWA standalone mode
**Depends on**: Phase 10
**Requirements**: VPT-01, VPT-02, VPT-03
**Success Criteria** (what must be TRUE):
  1. На iPhone с Dynamic Island/notch контент ридера не перекрывается системными элементами — safe area insets корректно применяются к header, footer и контенту
  2. При открытии клавиатуры (поиск, заметки) контент не прыгает и не сдвигается — клавиатура корректно обрабатывается через VisualViewport API
  3. В PWA standalone mode (добавление на домашний экран) навигация, статус-бар и все функции ридера работают корректно

### Phase 13: PWA и offline
**Goal**: Пользователь может установить приложение на домашний экран и читать книги без интернета с корректным управлением обновлениями
**Depends on**: Phase 9
**Requirements**: PWA-01, PWA-02, PWA-03, PWA-04, PWA-05
**Success Criteria** (what must be TRUE):
  1. Пользователь видит кастомный баннер установки PWA и может добавить приложение на домашний экран в один тап
  2. Без интернета пользователь может открыть приложение и читать ранее открытые книги — AI-фичи (entity wiki, генерация изображений) скрыты, а не показывают ошибки
  3. При выходе нового обновления Service Worker пользователь видит уведомление и может обновить приложение без потери позиции чтения
  4. При возврате из фона приложение не перезагружается без необходимости — градуированная стратегия (короткий фон: ничего, средний: проверка, долгий: reload)
  5. EPUB-файлы полностью кэшируются для чтения без интернета
